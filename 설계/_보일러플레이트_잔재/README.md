# 보일러플레이트 잔재 (참조 전용)

보일러플레이트(`spring_csr_boiler_react`) 시절 문서다. **이 프로젝트의 현행 기준이 아니다.**

사용자는 볼 필요 없고, 에이전트가 **보일러 유래 기능(인증·커뮤니티·채팅·파일)의 배경**을 확인할 때만 참조한다.
현행 기준은 상위 `설계/`의 01~08 문서다.

> ⚠️ 이 폴더의 문서에는 **지금과 다른 서술이 섞여 있다.**
> 예: 로컬 포트를 8080이라고 적은 곳(실제 8083), Thymeleaf 전환 시점의 서술, 자료실·코스 학습이 없던 시절의 기능 목록.
> 여기 적힌 내용과 상위 문서·코드가 다르면 **상위 문서와 코드가 맞다.**

## 왜 지우지 않았나

커뮤니티·채팅·파일·인증은 **이 프로젝트가 직접 설계한 것이 아니라 보일러플레이트에서 넘어온 기능**이다.
그 코드의 "왜 이렇게 돼 있는지"를 확인해야 할 때 원설계 문서가 남아 있는 편이 낫다.
학습(코스·자료실) 관련 내용은 여기 없다 — 전부 상위 01~08에 있다.
