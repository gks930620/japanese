## 이 폴더의 규칙

1. **여기 있는 것은 계속 유효해야 한다.** 시간이 지나 틀려진 서술을 발견하면 지우거나 고친다.
2. **코드가 기준이다.** 문서와 코드가 어긋나면 코드를 확인하고 문서를 고친다.
   (단 `code-convention` 스킬의 코딩 규칙은 반대다 — 그쪽은 문서가 기준이고 코드를 고친다.)
3. **진행 중인 것은 여기 두지 않는다.** 이터레이션 기획서·구현 현황·미결 항목은 `../진행사항/`으로.
4. **같은 사실을 두 문서에 적지 않는다.** 한 곳에 적고 다른 곳에서는 가리킨다.
