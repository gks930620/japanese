### 배포하려면 반드시 (아직 안 함)

1. **운영 시드 적재** — 운영은 `sql.init.mode: never`라 콘텐츠가 자동으로 안 들어간다.
   적재하지 않으면 사이트는 뜨지만 **코스 목록이 텅 빈다.**
   → **`gradlew prodSeedBundle`** 로 `build/prod-seed.sql` 하나를 만들어 1회 적재한다. 절차는 `../설계/07 §1`
2. **`railway-deploy` 스킬 채우기** — 실질 절차는 `07`에 있다.
3. **기동 거부 3조건 확인** — 편집 모드 `false` · **H2 콘솔 `false`** · 버킷 환경변수. → `../설계/07 §1-1`
4. **배포 시점 QA에서 비밀번호 최소 4자 재검토** — 기한 있는 유예다(`../설계/08 F-23`).
   **운영 계정이 0개인 지금이 바꾸기 가장 싸다.**
5. ⚠️ **이미 적재된 운영 DB에는 `UPDATE` 두 줄을 손으로 넣어야 한다** — `planned_unit_count`·`notice`.
   둘 다 *"배포하면 자동으로 되는 것"* 처럼 생겼는데 아니다: 컬럼은 `ddl-auto: update`가 만들지만 **값은 안 들어가고**,
   시드의 그 줄은 `sql.init.mode: never`라 운영에서 다시 돌지 않는다. **빠뜨려도 아무것도 실패하지 않고**
   운영 화면에만 거짓 안내가 남는다. 목록과 확인 쿼리는 `../설계/07 §1`.

> ✅ **QA 결함 수정은 끝났다**(커밋 `594055d`·`486c7de`) — 배포 전에 닫으려던 **SPA 폴백**이 그중 하나였다.
