## 2. 다음 순서

### 배포하려면 반드시 (아직 안 함)

1. **운영 시드 적재** — 운영은 `sql.init.mode: never`라 콘텐츠가 자동으로 안 들어간다.
   적재하지 않으면 사이트는 뜨지만 **코스 목록이 텅 빈다.** → `../설계/07 §1`
2. **`railway-deploy` 스킬 채우기** — 실질 절차는 `07`에 있다.
3. **기동 거부 3조건 확인** — 편집 모드 `false` · **H2 콘솔 `false`** · 버킷 환경변수. → `../설계/07 §1-1`
4. **배포 시점 QA에서 비밀번호 최소 4자 재검토** — 기한 있는 유예다(`../설계/08 F-23`).
   **운영 계정이 0개인 지금이 바꾸기 가장 싸다.**

## 5. 이 폴더의 규칙

1. **끝난 일은 지운다.** 단, **`설계/`로 옮기고 코드 주석 인용까지 바꾼 뒤에** 지운다.
   이 순서를 어기면 규칙이 조용히 사라진다 — 2026-08-31 정리에서 흡수 누락 5건이 이 순서 덕에 발견됐다.
2. **계속 유효한 규칙을 발견하면 `설계/`로 올린다.** 진행 문서에 규칙을 묻어 두지 않는다.
3. **상태가 바뀌면 이 README부터 고친다.** 여기가 "지금 뭐 하는 중인가"의 단일 출처다.
4. **수치는 코드·API 응답에서 센다.** 문서에서 문서로 베끼면 3단계 뒤처진 문서가 남는다.
