## 0. 시작하기 전에

| 항목 | 값 |
|---|---|
| 사이트 주소 | **`http://localhost:8103`** — 브라우저 주소창에 그대로 입력 |
| 테스트 계정 | 아이디 `user4` (또는 `user5`~`user12`), 비밀번호 `1234` |
| 주인 계정 | 아이디 `gks930620`, 비밀번호 `1234` |
| 비로그인 확인용 | **시크릿 창**(크롬 `Ctrl+Shift+N`)을 하나 더 띄워 두면 편하다 |

**미리 알아 둘 것 3가지**

1. **로그인하지 않아도 학습은 전부 볼 수 있다.** 코스·유닛·자료실·진단·보관함 모두 로그인 없이 열린다.
   로그인이 필요한 것은 **마이페이지**와 **커뮤니티 글쓰기·수정**뿐이다.
2. **비로그인일 때의 기록은 그 브라우저에만 남는다.** 시크릿 창을 닫으면 사라지는 게 정상이다.
3. **잠금이 없다.** 유닛 3을 안 봤어도 유닛 5로 바로 갈 수 있다. 이건 결함이 아니라 설계다.

## 2. 화면별 동작 — 여기서 이걸 누르면 이렇게 된다

### 2-1. 홈 (`/`)

- 큰 소개 문구 + **학습 시작 버튼** → 코스 목록 또는 이어서 볼 유닛으로.
- 코스 6장이 줄여진 카드로 보이고, 카드를 누르면 그 코스 상세로.
- **실력 진단 배너** → `/diagnosis`.
- 학습한 적이 있으면 시작 버튼 문구가 **"이어서 학습하기"**로 바뀐다.

### 2-2. 코스 목록 (`/courses`)

카드마다 배지가 하나 붙는다. **강조된 카드는 화면에 항상 딱 한 장**이어야 한다.

| 상황 | 배지 |
|---|---|
| 아직 아무것도 안 배웠다 | **여기서 시작하세요** (입문 카드에) |
| 배우던 코스를 아직 다 안 끝냈다 | **이어서 학습하기** |
| 배우던 코스를 끝냈다 | **다음 코스를 시작하세요** |
| 그 밖에 열려 있는 코스 | 바로 볼 수 있어요 (흐리게) |
| 유닛을 전부 끝낸 코스 | 완주 (흐리게) |
| 준비중 코스 | 준비중 — **눌러도 아무 데도 안 간다** |

### 2-3. 코스 상세 (`/courses/2`)

- 맨 위: 코스 이름 + 레벨 + 설명.
- **집계 줄**: 유닛 / 문법 / 한자 / 어휘 수 + 진도 막대("n 유닛 완료").
- **큰 버튼 1개**: 진도가 없으면 "유닛 1부터 시작하기", 있으면 "유닛 n 이어서 학습하기", 다 끝냈으면 "처음부터 다시 보기".
- 아래로 유닛 목록. 각 줄에 유닛 번호·제목·`문법 n · 회화 1 · 한자 n자 · 어휘 n개`.
- 끝낸 유닛에는 **✓ 완료** 표시. 이 표시는 **눌러서 끄는 버튼이 아니다**(읽기 전용).
- 이어서 볼 유닛에는 **여기부터** 배지.

### 2-4. 유닛 학습 (`/courses/2/units/1`) — 가장 중요한 화면

**스텝을 순서대로 넘기며 공부한다.** 스텝 수는 코스와 유닛에 따라 다르다(6~8개).

| 순서 | 스텝 이름 | 무엇이 보이나 |
|---|---|---|
| 1~3 | **문법①②③** | 문법 하나당 한 스텝. 이름·한국어 뜻·설명·예문(일본어/읽기/뜻) + 활용표(있는 것만) |
| 다음 | **회화** | 그 문법이 실제로 쓰인 대화. 말하는 사람 배지 + **전체 듣기** 버튼 |
| 다음 | **한자** | 글자 카드들. 훈음·음독·훈독·예시 단어 — **입문 코스에는 이 스텝이 아예 없다** |
| 다음 | **어휘** | 단어 · 읽는 법 · 뜻 3열 표. 가나뿐인 단어는 읽는 법 칸이 `─` |
| 다음 | **확인 문제** | 그 유닛 내용으로 매번 새로 만드는 4지선다 |
| 마지막 | **정리** | 배운 문법 목록 + 한자·어휘 개수 + 회화 제목, 완료 안내 + [다음 유닛 ›] |

> **확인 문제는 어휘 다음 · 정리 앞이고, 정리가 언제나 마지막 스텝이다.**
> 예전에는 정리 뒤 맨 끝이라 [다음 ›]만 눌러서는 닿을 수 없었다 — 2026-09-03 결정으로 앞으로 옮겨졌다(09 §2-1).
> 이 문서의 옛 표(정리 → 확인 문제)가 실물보다 늦었던 것이라 2026-09-21에 바로잡았다.

- **스텝 수**: 문법이 3개인 보통 유닛은 **8개**(문법3 + 회화 + 한자 + 어휘 + 확인 문제 + 정리).
  문법이 2개면 7개, **입문 코스는 한자 스텝이 없어 6개**(문법2 + 회화 + 어휘 + 확인 문제 + 정리)다. 유닛마다 개수가 다른 것이 정상이다.
- **[다음 ›]만 눌러도 확인 문제를 만난다.** [다음 유닛 ›]은 **정리 스텝에만** 있다 — 그 앞 스텝의 전진 버튼은 전부 [다음 ›]이고,
  확인 문제 카드의 전진 버튼도 [다음 ›]이며 **정리로** 간다.
- 위쪽 **스텝 칩은 전부 누를 수 있다** — 순서를 건너뛰어도 된다. 이전/다음 버튼도 있다.
- 스텝을 바꾸면 화면이 **맨 위로 올라간다.**
- 나갔다 다시 들어오면 **보던 스텝으로 돌아온다.** 단, 이미 완료한 유닛은 **1번 스텝부터** 열린다(복습이므로).
- **정리 스텝을 열면 그 유닛이 자동으로 완료**된다. 정리 스텝에서 손으로 껐다 켤 수 있다.
- 문법·한자·어휘 항목마다 **★(보관함 담기)** 가 있다. ★를 눌러도 자료실로 이동하지 않는다.
- 문법의 "자료실에서 보기", 한자 글자, 어휘 단어를 누르면 **새 탭**으로 자료실이 열린다(현재 사양).
- **마지막 유닛의 정리 스텝**에서는 다음 코스 안내가 나온다: 다음 코스가 있으면 "바로 이어갈 수 있어요" + 버튼, N1을 끝냈으면 "준비된 모든 코스를 완주했어요".

### 2-5. 확인 문제 (어휘 다음 · 정리 앞 스텝)

- **최대 10문항.** 문법 2~3 · 한자 3~4 · 어휘 4를 목표로 만든다.
- **문제를 풀지 않고 [다음 ›]으로 지나가도 된다** — 유닛 완료 조건은 정리 스텝에 닿는 것이지 문제 풀이가 아니다.
- **입문 코스는 6문항이 정상이다** — 한자를 안 배우니 한자 문항이 없다. 결함이 아니다.
- 보기는 항상 4개, 전부 다른 내용.
- 보기를 누르는 **즉시 채점**된다. 한 번 고르면 바꿀 수 없다.
- 다 풀면 점수와 함께 **[틀린 문제만 다시 풀기]** 가 나온다 — 새 문제가 아니라 **아까 틀린 그 문제 그대로**다.
- 틀린 문항에서 **자료실 해당 항목으로 바로 갈 수 있다.**
- **점수는 저장하지 않는다.** 유닛을 떠나면 사라진다 — 오답 노트·통계가 없는 이유다.

### 2-6. 실력 진단 (`/diagnosis`) — 레벨을 골라 한 판씩 *(2026-09-15 2차 개편 + 2026-09-16 3차 개편 반영)*

**계단이 아니다.** 레벨 하나를 골라 6문항을 풀고, 제출하면 **통과든 미달이든 결과 화면에서 멈춘다.** 이어서 할지는 매번 내가 고른다.

1. 들어가면 **레벨 고르기** 화면. 선택지는 **입문(문자) → 왕초보(JLPT N5) → … → 고급(JLPT N1)** 6개(열려 있는 코스의 레벨만). **가장 낮은 레벨이 이미 골라져 있다** — 잘 모르겠으면 그대로 [시작하기]. "최대 n단계"·"3분" 같은 말은 없다.
2. 문항 화면: **한 레벨 = 6문항이 한 화면에.** 위에 `{레벨} 레벨 · 6문항` 진행 줄. 문항은 **갈래 머리글** 아래 묶여 있고(입문~N3: `어휘`·`문법`·`문장` / N2·N1: `어휘`·`어법`), 번호는 1~6으로 이어진다. 머리글에 개수는 안 붙는다.
3. 보기는 **5개**(정답 후보 4 + 맨 아래 **[모르겠어요]**). 제출 전엔 몇 번이든 바꿀 수 있다.
   ★ **안 고른 문항이 하나라도 있으면 제출되지 않는다** *(2026-09-16 3차 개편으로 뒤집힘 — 08 F-30 · 09 §3-6. 예전 규칙은 "제출은 되고 모름으로 처리"였다)*:
   - 제출 버튼 위 한 줄은 **`아직 {n}문항을 고르지 않았어요 — 모두 고르면 제출할 수 있어요.`** (안 고른 게 0개면 줄이 통째로 없다)
   - 버튼은 **회색이 되지 않는다.** 그대로 누를 수 있고, 누르면 **번호가 가장 작은 안 고른 문항으로 화면이 올라가며** 그 문항의 첫 보기에 커서가 놓인다.
   - 그때부터 **안 고른 문항마다** `답을 골라 주세요 — 모르면 [모르겠어요]를 고르면 돼요.` 한 줄이 붙고, 답을 고르면 그 줄은 **즉시** 사라진다. (제출을 눌러 보기 전에는 이 줄이 어디에도 없다)
   - **"모름으로 처리"라는 말은 화면 어디에도 없고**, 확인 창(모달)도 없다.
   - **[모르겠어요]는 답이다** — 6문항 전부 [모르겠어요]로 골라도 안 고른 문항은 0이라 **그대로 제출되고** 0/6 미달이 된다.
4. 제출 버튼은 하나, 라벨은 언제나 **[제출하고 결과 보기 ›]**. **다 골랐을 때** 누르면 로딩 없이 바로 **결과 화면**(안 고른 문항이 있으면 ③처럼 막힌다). **푸는 동안에도, 제출 뒤에도 어느 문항이 맞았는지는 안 알려준다** — 정상이다.
5. 결과 화면: 캡션 `진단 결과 · {코스}({레벨})` + 가장 큰 글자가 **"이 레벨은 충분해요"**(통과 = 6문항 중 4개 이상) 또는 **"이 레벨은 아직 조금 어려워요"**(미달). 아래에 **판정표**(친 레벨만 · 레벨 순 · 레벨당 한 줄 · `4 / 6` 형식 · 판정은 `통과`/`—`) + 추천 한 줄 "지금 시작한다면 {코스} 코스가 좋아요."
6. 버튼은 최대 셋: 통과면 **[{위 레벨} 도전하기 ›]**, 미달이면 **[{아래 레벨} 확인하기 ›]** — 그 레벨이 목록 끝이거나 **이미 통과한 레벨이면 이 버튼이 없고** 문구가 대신 말한다("가장 높은 레벨까지 확인했어요…" / "여기가 가장 낮은 레벨이에요." / "아래 레벨은 이미 충분했어요…"). 그 밖에 [{추천 코스} 코스 시작하기] · [다른 레벨 고르기](기록은 남는다 — 레벨 목록에 `· 4 / 6`이 붙어 있다). **[끝내기] 버튼은 없다** — 안 누르면 그게 끝이다.
7. 같은 레벨을 다시 치면 판정표의 그 줄이 **새 결과로 바뀐다**(줄이 늘지 않는다). 같은 문제가 또 나올 수 있다(막지 않는다).
8. 레벨별 글자 규칙: 입문·N5는 히라가나만(한자·가타카나 없음), N4는 한자 + 읽는 법 줄(가타카나 없음), N3부터 가타카나 허용, N2·N1은 읽는 법 줄 없이 보기까지 일본어.
9. 문제를 못 만든 레벨은 **실패 카드**("{코스}({레벨}) 레벨은 문제를 준비하지 못했어요") + [지금까지 결과 보기](친 판이 없으면 [일단 입문부터 시작하기]) · [다른 레벨 고르기] · [다시 시도]. 판정표에 그 레벨 줄은 생기지 않는다.
10. **결과를 저장하지 않는다.** 새로고침하면 레벨 고르기로 돌아가고 판정표가 비워진다.

### 2-7. 자료실 (`/library/kanji` 등)

- **검색창 + 필터 칩**. 조건을 걸면 위에 **적용된 조건 칩**이 뜨고, 칩의 X로 하나씩, [초기화]로 전부 해제.
- 조건을 걸면 **주소가 함께 바뀐다** → 새로고침·뒤로가기·주소 공유로 그대로 복원된다.
- 결과가 0건이면 무엇 때문에 0건인지 문장으로 되읽어 주고 힌트를 준다.
- 결과 개수 줄 오른쪽에 **[이 조건으로 문제 풀기]** — 누르면 자료실 퀴즈로.
- 한자 탭의 레벨 선택지에는 **입문이 없다**(입문에 한자가 0자라서). 이건 정상이다.
- 어휘는 줄을 누르면 그 자리에서 펼쳐지고, 같은 단어의 여러 뜻과 "어디서 배우나"가 모두 나온다. 여러 줄을 동시에 펼칠 수 있다.

### 2-8. 자료실 퀴즈 (`/library/kanji/quiz`)

- **10문제 / 20문제**를 고르고 [문제 풀기].
- 진행·채점은 유닛 확인 문제와 같은 방식.
- 범위가 **4개 미만**일 때만 "이 조건으로는 문제를 낼 수 없어요" 안내가 나온다.

### 2-9. 보관함 (`/bookmarks`)

- **한자 · 문법 · 어휘 3탭.** 최근 담은 순 / 학습 순서로 정렬 전환.
- ★를 다시 누르면 빠진다. 종류별로 비우기도 있다.
- **로그인 안 해도 쓸 수 있다.** 이때는 그 브라우저에만 저장되고 종류별 200개까지다.
- 로그인하면 **"브라우저에 담아 둔 것을 계정에 합칠까요?" 를 묻는 띠**가 뜬다. 자동으로 합치지 않는다.

### 2-10. 영어 유닛 학습 (`/en/courses/101/units/1`)

일본어와 **같은 화면 틀**인데 한 자리만 바뀐다.

### 2-14. 뒤로가기·새로고침 (모든 화면 공통) *(2026-09-20 추가)*

- **되돌아올 때 로딩이 없다.** 한 번 본 화면(코스·유닛·자료실·커뮤니티 글)을 다시 열면 **회색 뼈대(스켈레톤) 없이 바로 내용**이 보인다.

  반대로 **링크를 눌러 새 화면으로 갈 때는 맨 위**에서 시작한다.
- **글을 쓰거나 고치거나 지운 뒤에는** 목록·댓글이 옛 내용으로 남지 않는다(그 자리만 다시 불러온다).

- **예외 — 실력 진단은 새로고침을 견디지 않는다.** 새로고침하면 레벨 고르기로 돌아가고 판정표가 비워진다(설계 그대로, §2-6 ⑩).

## 3. QA 체크리스트 — 순서대로 따라 하면 된다

> 전부 다 할 필요는 없다. **A → B → C 순서로 하면 30~40분**, 시간이 없으면 **C(되돌아왔는지 확인)만** 해도 값어치가 있다.

- [ ] **정상**: "이 레벨은 아직 조금 어려워요" + "여기가 가장 낮은 레벨이에요." + 추천 코스가 **입문(문자)**. 아래로 가는 버튼이 **없다**(비활성 버튼도 없다).
- [ ] **이상**: N5(왕초보)를 권하거나, 눌리지 않는 버튼이 남아 있으면 결함이다.

**C-5. N1 문제 보기에 입문 단어가 섞이지 않는가**

- [ ] `/courses/6/units/1` → 확인 문제 스텝. 문항을 하나하나 **보기 4개**를 읽어 본다.
- [ ] **정상**: 보기가 전부 비슷한 난이도의 N1급 항목이다.
- [ ] **이상**: `おはようございます` `これをください` 같은 입문 인사말이 보기에 섞이면 결함이다.
      (그러면 문제가 "뜻 맞히기"가 아니라 "쉬운 것 고르기"가 된다.)
- [ ] 여러 유닛(예: 유닛 1, 10, 25)에서 **몇 세트 반복**해 본다 — 매번 새로 만들기 때문이다.

**C-6. 검색 후 퀴즈를 여러 번 열어도 되는가**

- [ ] `/library/vocabulary` 에서 검색창에 **`하`** 를 친다.
- [ ] **[이 조건으로 문제 풀기]** 를 누른다 → 문제가 나오는지 본다.
- [ ] 뒤로 가서 **같은 동작을 5번 반복**한다.
- [ ] **정상**: 5번 다 문제가 나온다.
- [ ] **이상**: 그중 한 번이라도 "이 조건으로는 문제를 낼 수 없어요"가 뜨면 결함이다.
      (예전에 절반 확률로 실패하던 자리다. 한 번 성공했다고 넘어가지 말고 꼭 여러 번 하자.)

**C-7. 남의 글에 수정·삭제가 보이지 않는가**

- [ ] `user4` 로 로그인해 글을 하나 쓴다. 그 글 주소를 적어 둔다.
- [ ] 로그아웃하고 `user5` / `1234` 로 로그인한다.
- [ ] 아까 그 글을 연다.
- [ ] **정상**: 아래에 **[목록]만** 있고 수정·삭제 버튼이 **없다.** 남의 댓글에도 없다.
- [ ] 로그인하지 않은 상태로도 같은 글을 열어 본다 → 역시 수정·삭제가 없다.

**C-8. 로그인 5번 틀리면 안내가 나오는가** ⚠️

> **주의: 진짜로 15분 잠긴다.** 반드시 **테스트 계정(`user12` 등)** 으로 하고, 평소 쓰는 계정으로는 하지 말자.

- [ ] `/login` 에서 `user12` / **틀린 비밀번호**로 5번 연속 로그인한다.
- [ ] **정상**: **"로그인 시도가 너무 많아요. 15분 뒤에 다시 시도할 수 있어요."** 라고 나온다.
- [ ] **이상**: "잠시 후 다시 시도" 처럼 **얼마나 기다려야 하는지 안 알려주면** 결함이다(계속 눌러 잠금이 늘어난다).

**C-9. 마이페이지 [이어서 학습하기]가 404로 가지 않는가**

- [ ] `user4` 로 로그인한다.
- [ ] **영어** 유닛(`/en/courses/101/units/1`)을 열어 스텝을 두어 개 넘긴다.
- [ ] `/mypage` 로 간다 → **[이어서 학습하기]** 를 누른다.
- [ ] **정상**: 방금 보던 **영어 유닛**으로 돌아간다. 안내 문구도 그 영어 코스 이름을 말한다.
- [ ] **이상**: 404("없는 주소")로 가거나, 엉뚱한 일본어 코스로 가면 결함이다.
- [ ] 이어서 **일본어** 유닛을 하나 열고 다시 마이페이지로 → 이번엔 그 일본어 유닛으로 간다.

**C-10. 가장 높은 레벨을 통과하면 없는 코스를 약속하지 않는가**

- [ ] `/diagnosis` → 레벨 고르기에서 **고급(JLPT N1)** 을 골라 [시작하기] → 6문항 중 4개 이상 맞힌다.
      쉬운 방법: 문제를 열어 두고 자료실에서 답을 찾아 맞혀도 된다. 목적은 결과 화면 확인이다.
- [ ] **정상**: "이 레벨은 충분해요" + "가장 높은 레벨까지 확인했어요 — 더 볼 위 레벨이 없어요." + 추천이 **고급(N1) 코스**. 위로 가는 버튼이 **없다.**
- [ ] **이상**: **"그 위 코스는 준비 중이에요"** 가 뜨면 결함이다 — N1이 마지막이라 그 위는 없다.

**C-11. N2만 골라 통과하면 N1을 권하는가** *(2차 개편이 "조용히 틀리는 자리"로 지목 — 기획서 A38)*

- [ ] `/diagnosis` → **중상급(JLPT N2)** 을 골라 [시작하기] → 6문항 중 4개 이상 맞힌다(자료실에서 답을 찾아도 된다).
- [ ] **정상**: 주 버튼이 **[JLPT N1 도전하기 ›]**, 추천 한 줄이 **"지금 시작한다면 고급(JLPT N1) 코스가 좋아요."**
- [ ] **이상**: 왕초보(N5)나 다른 낮은 코스를 권하면 결함이다 — 옛 계산("맨 아래부터 연속 통과 수")이 남은 것이다.

## 4. 이상한 걸 찾으면 어떻게 알려주나

**한 줄로 "안 돼요"라고 하면 고치는 데 하루가 걸리고, 아래 4가지를 적어 주면 30분이면 된다.**

| 적어 줄 것 | 예시 |
|---|---|
| **① 주소** | `localhost:8103/courses/6/units/1` |
| **② 누른 순서** | 확인 문제 스텝 클릭 → 3번째 문항 |
| **③ 기대한 것** | 보기 4개가 전부 N1급 단어여야 함 |
| **④ 실제로 본 것** | 보기에 `おはようございます` 가 섞여 있었음 |

**함께 있으면 훨씬 좋은 것**

- **스크린샷** — 화면 전체가 나오게(`Windows 키 + Shift + S` 로 잘라서 붙여넣기). 주소창이 함께 찍히면 최고다.
- **로그인 상태** — 로그인했는지, 했다면 어떤 아이디였는지.
- **몇 번 만에 나왔는지** — "한 번에", "5번 중 2번", "매번". 무작위로 만들어지는 화면(확인 문제·진단·자료실 퀴즈)에서는 이게 결정적이다.
- **창 크기** — 컴퓨터 화면인지 휴대폰(또는 좁은 창)인지.

**이렇게 적어 주면 좋은 예**

```
주소: localhost:8103/mypage
순서: user4로 로그인 → 영어 유닛 1 보다가 → 마이페이지 → [이어서 학습하기] 클릭
기대: 보던 영어 유닛으로 돌아감
실제: "없는 주소입니다" 화면이 떴음
빈도: 3번 중 3번 (매번)
화면: 노트북, 로그인 상태
(스크린샷 첨부)
```

**반대로, 결함이 아닌 것들** — 아래는 신고하지 않아도 된다(전부 의도된 동작이다).

- 입문 코스에 한자가 없고 확인 문제가 6문항인 것
- 영어 유닛에 확인 문제·듣기 버튼이 없는 것
- 컴퓨터에 일본어 음성이 없어 듣기 버튼 자체가 안 보이는 것
- 퀴즈·진단 점수가 저장되지 않는 것 (오답 노트·통계는 만들지 않기로 확정). 진단 판정표도 새로고침하면 비워진다
- 진단에서 통과해도 **다음 레벨 문항이 자동으로 뜨지 않는 것** — 결과 화면에서 멈추고 [도전하기]를 눌러야 이어진다(설계)
- 진단 결과 화면에 [끝내기] 버튼이 없는 것 — 아무것도 안 누르면 그게 끝내기다
- 진단에서 **안 고른 문항이 있으면 제출이 안 되고** 그 문항으로 화면이 올라가는 것 (2026-09-16 결정 08 F-30 — [모르겠어요]가 이미 있으니 빈칸은 의사 표시가 아니라 실수로 본다)
- 그때 제출 버튼이 **회색으로 바뀌지 않는 것** — 눌러야 "어디를 채워야 하는지"를 알려줄 수 있다(회색 버튼은 그걸 못 한다)
- 유닛에서 **확인 문제가 정리보다 앞**에 오는 것 — [다음 ›]만 눌러도 문제를 만나게 하려고 옮긴 자리다(09 §2-1)
- 뒤로 돌아왔을 때 **로딩 없이 바로 내용이 보이고** 잠시 뒤 내용이 슬쩍 갱신되는 것 (§2-14)
- 진단 N2·N1의 빈칸 문항에 "이 문법의 뜻은?" 같은 질문 줄이 없고 `어법` 머리글만 있는 것
- 진단 입문·N5에 한자·가타카나가 전혀 안 나오고, N2·N1은 보기까지 전부 일본어인 것 (레벨별 표기 규칙)
- 유닛 순서가 강제되지 않고 아무 유닛이나 열리는 것
- 아이디·비밀번호 찾기 화면이 없는 것
- 자료실 링크가 새 탭으로 열리는 것 (같은 탭으로 바꾸는 건 다음 과제)
- 문법 중 활용표가 없는 것이 많은 것 (295개 중 87개에만 있다)
- 어휘 자료실에 상세 화면이 없고 줄이 펼쳐지는 것

## 6. 이 문서를 언제 다시 보나

- **화면을 고친 뒤** — §3 체크리스트로 되돌아온 것이 없는지 확인한다.
- **디자인 킷을 바꾼 뒤**(Halo → Lets) — 색·모양은 달라져도 **§1 화면 구성과 §2 동작은 그대로여야 한다.**
  달라진 것이 있으면 그건 디자인 교체가 아니라 결함이다.
- **인터넷에 올리기(배포) 직전** — §3 A·B·C 전체를 한 바퀴 돈다.
  ⚠️ 올린 사이트에서는 **편집 모드 띠가 사라지는 것**이 정상이고, 콘텐츠(코스·자료실)가 비어 보이면 준비 절차가 빠진 것이다.
