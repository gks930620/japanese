# QA — 무엇을 보고, 어떻게 보고, 무엇을 확인하나

> **QA 문서는 이것 하나다.** 예전엔 "어떻게 보는가"와 "무엇을 확인하나"가 두 파일로 갈려 같은 말을 두 번 하고 있었다 —
> 합치고 낡은 부분을 덜어냈다. 순서: **무엇이 있나(§1) → 어떻게 보나(§2) → 체크리스트(§3) → 적는 법(§4)**.
>
> **누가 읽나**: 이 사이트를 **브라우저로 직접 눌러 보며** 확인하는 사람. 터미널·코드를 몰라도 되게 **주소·화면·버튼**으로만 적었다.
> **색·글꼴 이야기는 하지 않는다** — 겉모습은 바뀌어도 화면 구성·동작·상태는 그대로다.

**기준: 2026-11-13 · 커밋 `78eab33`.** §1의 수치는 **실행 중인 서버 응답과 화면 코드에서 직접 확인한 값**이다.
수치가 적힌 자리는 베끼지 말고 다시 재라 — 재는 방법은 `현재_기능현황.md` §8.

## 0. 시작 전에

| 항목 | 값 |
|---|---|
| 주소 | **`http://localhost:8103`** |
| 테스트 계정 | `user4`~`user12` / `1234` · 남의 글 확인용 두 번째 계정 `user5` · 주인 계정 `gks930620` |
| 비로그인 확인 | **시크릿 창**(`Ctrl+Shift+N`)을 하나 더 띄워 둔다 |

> ⚠️ **서버는 `java -jar`로 띄운다.** `gradlew bootRun`으로 띄우면 테스트를 한 번 돌릴 때 데몬이 그 서버를 죽인다(`작업자(AI)_문서/02` §5-1).
> QA 중 서버가 반복해서 죽으면 이것이 원인이다.

**미리 알아 둘 것 3가지**

1. **로그인 없이도 학습은 전부 된다.** 로그인이 필요한 곳은 **마이페이지**와 **커뮤니티 글쓰기·수정**뿐이다.
2. **비로그인 기록은 그 브라우저에만 남는다.** 시크릿 창을 닫으면 사라지는 게 정상이다.
3. **잠금이 없다.** 유닛 3을 안 봤어도 유닛 5로 바로 간다. 결함이 아니라 설계다.

**도구 세 개** — 브라우저 하나로 끝난다.

| 도구 | 여는 법 | 무엇에 쓰나 |
|---|---|---|
| **개발자도구** | `F12` | **Network** 탭의 속도를 `Slow 3G`(느린 사람)·`Offline`(끊긴 사람)으로. **Console** 탭의 빨간 줄만 본다(내용은 몰라도 된다 — 화면 이름과 함께 적어 넘긴다). `Ctrl+Shift+M`으로 휴대폰 화면 |
| **시크릿 창** | `Ctrl+Shift+N` | 로그인 안 한 사람의 눈. 기존 로그인과 섞이지 않는다 |
| **주소창** | 늘 보이는 그것 | **직접 주소를 쳐서 들어가기.** QA에서 제일 강한 무기다 |

> **왜 `Slow 3G`를 배우나**: QA에서 놓치기 제일 쉬운 게 **"내 컴퓨터가 너무 빨라서 못 본 것"** 이다.
> 로딩 화면은 0.05초에 지나가 아무도 못 보는데, 지하철에서 접속한 사람은 5초 동안 본다. `Slow 3G`가 그 5초를 보여준다.

**정상을 알아야 이상한 걸 찾을 수 있다.** 여기가 "정상"의 기준이고, §3 체크리스트는 이걸 손에 들고 도는 것이다.

## 1-1. 일본어 학습 (사이트의 주인공)

| 주소 | 화면 | 무엇을 하는 곳인가 |
|---|---|---|
| `/` | 홈 | **이 사이트가 무엇인지 설명하는 화면.** 코스 카드를 늘어놓지 않는다 |
| `/courses` | 코스 목록 | 코스 6장 + 상단 안내 띠 1개 |
| `/courses/1`~`/courses/6` | 코스 상세 | 입문(10) · 왕초보 N5(20) · 초급 N4(20) · 중급 N3(25) · 중상급 N2(25) · 고급 N1(25) |
| `/courses/2/units/1` | 유닛 학습 | **실제로 공부하는 화면.** 스텝을 순서대로 넘긴다 |

> 일본어 코스 6개는 **전부 열려 있다.** "준비중"으로 표시되는 일본어 코스는 하나도 없어야 정상이다.

**홈 (`/`)** — 히어로(소개 문구 + [학습 시작하기] → 코스 목록, 학습한 적이 있으면 **이어보기**로 바뀜) → **진단 안내 띠 + [내 시작점 찾기]**(항상)
→ 강점 카드 3장 → **"지금 배울 수 있는 것" 수치**(코스·유닛·한자·문법·어휘) → 유닛 흐름 6단계 → 자료실 소개 → [코스 보러 가기].
**코스 카드가 없다** — 코스를 늘어놓는 건 `/courses`의 일이다. (예전 문서의 "홈에 코스 6장"은 지금 사실이 아니다.)
수치는 **서버에서 받아 그리는 살아 있는 값**이고, **아직 안 온 수치는 0으로 채우지 않고 안 그린다.**

**코스 목록 (`/courses`)** — **상단 안내 띠는 언제나 딱 하나**다: 진도 없으면 어디부터 시작하라는 안내 + [내 시작점 찾기] /
진도 있으면 지금 코스가 맞는지 다시 확인하라는 안내 + [내 시작점 찾기] / 전부 완주면 `✎ 준비된 코스를 모두 마쳤어요`(**진단 버튼 없음**).
카드 배지는 여섯 가지이고 **강조 카드는 항상 딱 한 장**이다.

| 상황 | 배지 |
|---|---|
| 아직 아무것도 안 배웠다 | **여기서 시작하세요** (입문 카드에) |
| 배우던 코스가 아직 안 끝났다 | **학습 중인 코스** |
| 배우던 코스를 끝냈다 | **다음 코스를 시작하세요** |
| 그 밖에 열린 코스 / 전부 끝낸 코스 / 준비중 | 바로 볼 수 있어요 · ✓ 완주 · 준비중 (셋 다 흐리게. 준비중은 **눌러도 안 간다**) |

코스에 `notice`가 있으면 카드 아래에 `✎` 한 줄이 붙는다 — 일본어는 왕초보(N5)에만, 영어는 E2에만 있다.

**코스 상세 (`/courses/2`)** — 이름·레벨·설명(영어는 레벨 괄호 없음) → **집계 줄**(유닛/문법/한자/어휘 + 진도 막대, 전부 API 집계값)
→ **큰 버튼 1개**("유닛 1부터 시작하기" / "유닛 n 이어서 학습하기" / "처음부터 다시 보기") → 유닛 목록.
각 줄에 `문법 n · 회화 1 · 한자 n자 · 어휘 n개`이고 **값이 0인 항목은 구분점까지 통째로 빠진다**(입문에 "한자 0자"가 없는 이유).
끝낸 유닛에 **✓ 완료**(읽기 전용, 누르는 버튼이 아니다), 이어서 볼 유닛에 **여기부터** 배지.

**유닛 학습 (`/courses/2/units/1`) — 가장 중요한 화면.** 스텝 순서는 고정이다:

| 순서 | 스텝 | 무엇이 보이나 |
|---|---|---|
| 1~3 | **문법①②③** | 문법 하나당 한 스텝. 이름·뜻·설명·예문(일본어/읽기/뜻) + 활용표(있는 것만) |
| 다음 | **회화** | 그 문법이 쓰인 대화. 말하는 사람 배지 + **전체 듣기** |
| 다음 | **한자** | 글자 카드(훈음·음독·훈독·예시) — **입문 코스에는 이 스텝이 아예 없다** |
| 다음 | **어휘** | 단어 · 읽는 법 · 뜻 3열. 가나뿐인 단어는 읽는 법이 `─` |
| 다음 | **확인 문제** | 매번 새로 만드는 4지선다 |
| 마지막 | **정리** | 배운 것 요약 + 완료 토글 + [다음 유닛 ›] |

- **확인 문제는 어휘 다음 · 정리 앞이고 정리가 언제나 마지막**이다. [다음 ›]만 눌러도 확인 문제를 만난다. **[다음 유닛 ›]은 정리에만** 있다.
- **스텝 수는 유닛마다 다른 것이 정상**이다 — 문법 3개면 8개, 2개면 7개, **입문은 한자 스텝이 없어 6개**.
- 스텝 칩은 **전부 누를 수 있다**(건너뛰어도 된다). 스텝을 바꾸면 화면이 **맨 위로** 올라간다.
- 나갔다 다시 들어오면 **보던 스텝으로** 돌아온다. 단 **이미 완료한 유닛은 1번 스텝부터**(복습이므로).
- **정리를 열면 자동으로 완료**된다. 정리에서 손으로 껐다 켤 수 있다.
- 항목마다 **★(보관함 담기)** — ★를 눌러도 자료실로 이동하지 않는다. 문법 "자료실에서 보기"·한자·어휘를 누르면 **새 탭**이 열린다(현재 사양).
- **마지막 유닛의 정리에서 코스의 끝이 세 갈래로 갈린다**: 다음 코스가 열려 있으면 "바로 이어갈 수 있어요" + 버튼 /
  준비중이면 "지금 준비하고 있어요 + 자료실에서 다시 볼 수 있어요" / 마지막 코스면 "준비된 모든 코스를 완주했어요".
  **계획보다 적게 열린 코스는 완주가 아니라 "열린 데까지의 끝"** 이다(§1-4).

**확인 문제** — **최대 10문항**(문법 2~3 · 한자 3~4 · 어휘 4). **입문은 6문항이 정상**(한자를 안 배운다).
보기는 항상 4개 전부 다른 내용, 누르는 **즉시 채점**되고 **한 번 고르면 못 바꾼다.**
풀지 않고 지나가도 된다(완료 조건은 정리에 닿는 것이다). 끝나면 **[틀린 문제만 다시 풀기]** — 새 문제가 아니라 **아까 틀린 그 문제 그대로**다.
틀린 문항에서 자료실로 바로 갈 수 있다. **점수는 저장하지 않는다** — 오답 노트·통계가 없는 이유다.

## 1-2. 자료실과 퀴즈 (부록)

| 주소 | 화면 | 내용 |
|---|---|---|
| `/library` | — | 열면 곧바로 한자 자료실로(허브 화면 없음) |
| `/library/kanji` · `/library/kanji/1` | 한자 목록·상세 | **1,350자**, 한 쪽에 **60**. 상세는 훈음·음독·훈독·예시 + "어디서 배우나" |
| `/library/grammar` · `/library/grammar/1` | 문법 목록·상세 | **295개**, 한 쪽에 **20**. "활용표 있는 것만" 토글(켜면 **87**) |
| `/library/vocabulary` | 어휘 목록 | 표제어 **1,734개**, 한 쪽에 **50**. 품사 7종. **상세 화면 대신 줄을 펼친다** |
| `/library/kanji/quiz` | 자료실 퀴즈 | 지금 걸어 둔 조건 그대로 10 / 20문제 (`kanji` 자리에 `grammar`·`vocabulary`도 된다) |

- **검색창 + 필터 칩.** 조건을 걸면 **적용된 조건 칩**이 뜨고 X로 하나씩·[초기화]로 전부 해제.
- 조건을 걸면 **주소가 함께 바뀐다** → 새로고침·뒤로가기·주소 공유로 복원된다.
- 0건이면 **무엇 때문에 0건인지** 문장으로 되읽어 주고 힌트를 준다. 개수 줄 오른쪽에 **[이 조건으로 문제 풀기]**.
- **레벨 선택지는 일본어 6개**(입문·N5·N4·N3·N2·N1)인데 **한자 탭만 입문이 없다**(한자가 0자라서). 영어는 E1~E5.
- 어휘는 줄을 누르면 그 자리에서 펼쳐지고 여러 줄을 동시에 펼칠 수 있다.
  **표제어는 "표기 + 읽기"로 묶인다** — 읽기가 다르면 다른 단어다(§3-C-12).
- 퀴즈는 들어오면 **범위를 문장으로 되읽어 준다**("N3 한자 350개 중에서 출제합니다").
  **범위가 4개 미만일 때만** "문제를 낼 수 없어요"가 나온다 — 4건 이상이면 **반드시** 문제가 나와야 한다.

## 1-3. 학습 도구

| 주소 | 화면 | 무엇을 하는 곳인가 |
|---|---|---|
| `/diagnosis` | 실력 진단 | 레벨을 골라 **6문항 한 판**. 통과/미달 판정 + 시작할 코스 추천 |
| `/bookmarks` | 내 보관함 | ★로 담은 한자·문법·어휘 3탭. 최근 담은 순 / 학습 순서 정렬 |

**보관함** — ★를 다시 누르면 빠진다. 종류별 비우기도 있다. **로그인 없이도 쓸 수 있고** 그때는 그 브라우저에만 저장되며 **종류별 200개까지**다.
로그인하면 **"브라우저에 담아 둔 것을 계정에 합칠까요?" 띠**가 뜬다 — **자동으로 합치지 않는다.**

**실력 진단 (`/diagnosis`) — 계단이 아니다.** 레벨 하나를 골라 6문항을 풀고, 제출하면 **통과든 미달이든 결과 화면에서 멈춘다.**
이어서 할지는 매번 내가 고른다. 진단은 **상단 메뉴에 없다** — 홈과 코스 목록의 안내 띠로만 들어간다.

1. **레벨 고르기**: 입문(문자) → 왕초보(N5) → … → 고급(N1) **6개**, **가장 낮은 레벨이 이미 골라져 있다.**
   ⚠️ **화면이 총량을 약속하지 않는다** — 소요 시간·판 수·문항 수·"최대 n단계"·자동 진행을 암시하는 말이 **진단 화면에도 유입 배너에도 없어야** 한다.
2. **문항 화면**: 6문항이 **한 화면에**. 위에 `{레벨} 레벨 · 6문항` 진행 줄. 문항은 **갈래 머리글** 아래 묶인다
   (입문~N3: `어휘`·`문법`·`문장` / N2·N1: `어휘`·`어법`). 번호는 1~6으로 이어지고 머리글에 개수는 안 붙는다.
3. 보기는 **5개**(정답 후보 4 + 맨 아래 **[모르겠어요]**). 제출 전엔 몇 번이든 바꿀 수 있다.
   ★ **안 고른 문항이 하나라도 있으면 제출되지 않는다**:
   - 제출 버튼 위 한 줄 `아직 {n}문항을 고르지 않았어요 — 모두 고르면 제출할 수 있어요.` (0개면 줄이 통째로 없다)
   - 버튼은 **회색이 되지 않는다.** 누르면 **번호가 가장 작은 빈 문항으로 화면이 올라가며** 그 문항 첫 보기에 커서가 놓인다.
   - 그때부터 **빈 문항마다** `답을 골라 주세요 — 모르면 [모르겠어요]를 고르면 돼요.` 가 붙고 답을 고르면 **즉시** 사라진다.
   - **"모름으로 처리"라는 말은 화면 어디에도 없고** 확인 창도 없다.
   - **[모르겠어요]는 답이다** — 6문항 전부 그것으로 골라도 빈 문항은 0이라 **제출되고** 0/6 미달이 된다.
4. 제출 버튼은 하나, 라벨은 언제나 **[제출하고 결과 보기 ›]**. 다 골랐으면 로딩 없이 바로 결과다.
   **푸는 동안에도 제출 뒤에도 어느 문항이 맞았는지는 안 알려준다** — 정상이다.
5. **결과 화면**: 캡션 `진단 결과 · {코스}({레벨})` + 가장 큰 글자가 **"이 레벨은 충분해요"**(통과 = 6문항 중 **4개 이상**) 또는
   **"이 레벨은 아직 조금 어려워요"**(미달). 아래에 **판정표**(친 레벨만 · **레벨 순** · 레벨당 한 줄 · `4 / 6` 형식 · 판정은 `통과`/`—`)
   + 추천 한 줄 "지금 시작한다면 {코스} 코스가 좋아요."
6. 버튼은 최대 셋: 통과면 **[{위 레벨} 도전하기 ›]**, 미달이면 **[{아래 레벨} 확인하기 ›]**.
   목록 끝이거나 **이미 통과한 레벨이면 버튼이 없고** 문구가 대신 말한다. 그 밖에 [{추천 코스} 코스 시작하기] · [다른 레벨 고르기].
   **[끝내기] 버튼은 없다** — 안 누르면 그게 끝이다.
7. 같은 레벨을 다시 치면 판정표의 그 줄이 **새 결과로 바뀐다**(줄이 늘지 않는다). 같은 문제가 또 나올 수 있다.
8. 레벨별 글자 규칙: 입문·N5는 히라가나만, N4는 한자 + 읽는 법 줄, N3부터 가타카나 허용, N2·N1은 읽는 법 줄 없이 보기까지 일본어.
9. 문제를 못 만든 레벨은 **실패 카드** + [지금까지 결과 보기] · [다른 레벨 고르기] · [다시 시도]. 판정표에 그 줄은 생기지 않는다.
10. **결과를 저장하지 않는다.** 새로고침하면 레벨 고르기로 돌아가고 판정표가 비워진다.

## 1-4. 영어 학습 — 코스 **2개** 공개 (101 완성 · 102 부분)

| 주소 | 화면 | 무엇을 하는 곳인가 |
|---|---|---|
| `/en` | — | 열면 곧바로 영어 코스 목록으로 |
| `/en/courses` | 영어 코스 목록 | 코스 5장. **2장이 열려 있고 3장(E3·E4·E5)은 준비중** |
| `/en/courses/101` | E1 「다시 세우기」 | 유닛 **15개**(계획 15 = 공개 15 → **완성**). **`✎` 안내 띠가 없어야** 정상 |
| `/en/courses/102` | E2 「일상 말하기」 | 유닛 **5개**(계획 **20** 중 5 → **부분 공개**). 맨 위에 **`✎` 채우는 중 안내 한 줄**이 붙는다 |
| `/en/courses/101/units/15` | E1 마지막 유닛 | 정리가 **완주**다(복습 블록 11~15 포함) |
| `/en/courses/102/units/5` | E2 마지막 열린 유닛 | 정리가 **"열린 데까지의 끝"**(복습 블록 1~5 포함). **완주 축하가 뜨면 결함** |
| `/en/start` | 영어 시작점 안내 | 문제·채점이 **없다.** "지금 뭘 말할 수 있나"를 고르면 코스로 보낸다. 저장하지 않는다 |
| `/en/library/expressions`(+`/9001`) · `/en/library/grammar` · `/en/library/vocabulary` | 영어 자료실 | 표현 **138** · 문법 **57** · 어휘 표제어 **317**. `/en/library`는 표현으로 넘어간다 |

**영어 유닛 학습** — 일본어와 **같은 화면 틀**인데 몇 자리만 바뀐다.

- 한자 스텝 자리에 **표현** 스텝. 정리에서는 표현을 칩으로 깔지 않고 **개수만** 적는다.
- 어휘·표현에 **발음기호 + 한글 근사 표기**가 붙는다.
- **확인 문제 스텝이 없다. 듣기(음성) 버튼도 없다.** → **이게 정상이다.** 일부러 끈 것이며 유닛이 늘어도 그대로다.
- **유닛 5·10·15의 정리에 복습 블록**이 붙는다(`유닛 번호 % 5 == 0`): 5 → 1~5, 10 → 6~10, 15 → 11~15.
  그 밖의 유닛에는 없는 게 정상이고, **E2 유닛 5에도 복습 블록 1~5가 있다.**

> ★ **"완주"와 "열린 데까지의 끝"은 다른 상태다.** 가르는 근거는 사람이 켜는 깃발이 아니라 **개수 비교**다
> (열린 유닛 수 < 계획 유닛 수 → 아직 완주가 아니다). **E1은 15/15라 완주, E2는 5/20이라 열린 끝**이다.
> 그래서 **E2를 더 채우면 저절로 완주로 바뀐다** — 문구를 손으로 고치는 자리가 아니다.
> E1 유닛 15는 다음 코스 E2가 **열려 있으므로** "바로 이어갈 수 있어요" + 버튼이 함께 나온다.

## 1-5. 계정 · 커뮤니티 · 그 밖

| 주소 | 로그인 | 정상 동작 |
|---|:---:|---|
| `/login` | — | 아이디·비밀번호 + 카카오·구글. **5번 틀리면 15분 잠긴다**(안내에 **15분**이 적혀야 한다) |

| `/mypage/withdraw` | ✅ | 무엇이 지워지는지(완료 유닛·보관함·글·댓글 수) **먼저 보여주고** 확인받는다 |
| `/community` · `/community/detail?id=1` | — | 제목/작성자 검색(본문 검색 없음) + 쪽 넘김. 글을 열면 조회수 +1. 첨부는 로그인 없이도 내려받는다 |

> **아이디·비밀번호 찾기는 없다.** 만들지 않기로 확정된 것이라 화면에 없는 게 정상이다.
> **댓글 쪽을 넘기면 주소 끝에 `?cpage=`** 가 붙어 새로고침해도 그 쪽이 열린다. 1쪽으로 오면 사라지고, 댓글을 새로 쓰면 1쪽으로 돌아간다.

**상단 메뉴(모든 화면 공통)** — 로고(→홈) · **과정 스위처**(일본어/영어, 보고 있는 쪽이 켜짐) ·
**메뉴 3개 고정**(학습 → 자료실 → 커뮤니티, **채팅 없음**) · 밝게/어둡게 · 로그인(또는 마이페이지+닉네임+로그아웃).
영어 화면에서는 같은 3칸이 **영어 쪽 목적지**로 갈아 끼워진다(자료실 → 영어 표현 자료실). 화면이 좁으면 **햄버거**로 접힌다.

**편집 모드(내 컴퓨터에서만)** — 모든 화면 맨 위에 **편집 모드 띠**가 상시로 붙고, 자료실 줄·한자/문법 상세·유닛 학습에서
한자·문법·어휘·회화를 그 자리에서 고친다(**추가·삭제는 없고 수정만**). **관리자 기능이 아니다** — 로그인과 무관하고,
인터넷에 올린 사이트에는 아예 나타나지 않는다(켜면 기동을 거부한다).

## 1-6. 모든 화면 공통 — 뒤로가기·새로고침

- **되돌아올 때 로딩이 없다.** 한 번 본 화면을 다시 열면 **회색 뼈대 없이 바로 내용**이 보인다.
  뒤에서 조용히 다시 불러 최신으로 바꾸므로 내용이 잠깐 뒤에 바뀌는 것은 정상이다.
- **보던 자리로 돌아간다.** 목록을 한참 내려가다 글을 열고 **뒤로** 가면 그 자리로(맨 위가 아니다).
  반대로 **링크를 눌러 새 화면으로 갈 때는 맨 위**에서 시작한다.
- 글을 쓰거나 고치거나 지운 뒤 목록·댓글이 옛 내용으로 남지 않는다.
- 자료실에서 쪽을 넘기거나 조건을 바꾸면 목록이 사라졌다 나타나지 않고 **흐려졌다 갈아끼워진다.**
- **예외 — 실력 진단은 새로고침을 견디지 않는다.** 설계 그대로다(§1-3 ⑩).

# §2. 어떻게 보나 — 보는 눈

§1은 **답안지**다. 언젠가 소진된다. §2는 **문제를 만드는 법**이다.
체크리스트를 다 돌았는데 더 볼 게 없어 보인다면, 볼 게 없는 게 아니라 **보는 법을 아직 안 쓴 것**이다.

## 2-1. "빌드되고 테스트 통과"는 출발선이지 결승선이 아니다

테스트가 1,100건 통과했다는 말은 **"개발자가 예상한 상황에서는 예상한 대로 돈다"** 는 뜻이다. 이 셋은 한 줄도 보증하지 않는다.

| 기계가 못 보는 것 | 왜 |
|---|---|
| **규칙이 말이 되는가** | 테스트는 "코드가 규칙대로 도는가"를 본다. **그 규칙 자체가 이상한 것**은 통과한다 |
| **사람이 쓰기에 어떤가** | "버튼을 누르면 이동한다"는 통과한다. **"이 버튼까지 5번을 눌러야 한다"** 는 아무도 안 본다 |
| **화면이 실제로 어떻게 보이는가** | 데이터가 0개라 빈 상자만 남는 것도 테스트는 "정상"으로 센다 |

> 실제로 있었던 일: 영어 자료실은 서버 기능·화면 부품·화면정의서가 다 있고 테스트도 통과했는데
> **주소가 연결돼 있지 않아 404**였다. 기계는 전부 초록불이었다 — **"만들었다"와 "닿을 수 있다"는 다르다.**

## 2-2. 사람이 보는 다섯 가지 — 어느 종류인지 구분해야 누구에게 넘길지가 정해진다

| # | 종류 | 질문 | 예 |
|---|---|---|---|
| ① | **비즈니스 로직** | 이 제품이 정한 **규칙대로** 도는가 | 진단에서 다 틀렸는데 **N2 코스를 추천**하면 안 된다 |
| ② | **화면 상태** | 데이터가 0개/1개/아주 많을 때도 **말이 되는가** | 입문 코스에 **"한자 0자"** 가 적혀 있으면 안 된다 |
| ③ | **사용자 불편** | 되긴 되는데 **짜증나는가** | 자료실 링크가 새 탭으로 열려 탭이 20개 쌓인다 |
| ④ | **설계·로직의 이상함** | 되는데 **왜 이렇게 되지?** | 퀴즈를 다 풀었는데 점수가 안 남는다 → 의도인가 빠뜨린 건가 |
| ⑤ | **문서 오류** | 문서대로 했는데 **안 되는가** | 문서엔 "레벨 필터 4개"인데 실제는 6개다 |

**①②는 결함**이니 개발자에게. **③④는 "이게 의도인가?"를 물어야** 한다. **⑤는 실물이 사실**이니 문서를 고친다.

> **④를 그냥 넘기지 마라.** "되니까 됐다"고 넘긴 것 중에 나중에 제일 크게 터지는 게 많다.
> 퀴즈 점수를 저장하지 않는 것은 **의도된 결정**이지만 모르는 사람이 보면 버그다.
> **의도인지 결함인지 구분이 안 되는 것 자체가 리포트감**이다.

## 2-3. 화면 하나에 상태는 여섯 개다 ★이 문서에서 제일 중요한 절

사람들은 **"잘 되는 경우"** 하나만 본다. 같은 화면 하나에도 사용자가 마주치는 모습은 최소 여섯 가지다.
개발자는 보통 첫 번째만 확인하고 넘어간다. **나머지 다섯이 QA의 사냥터**다.

| 상태 | 어떻게 만드나 | 무엇이 정상인가 | 이 사이트에서 볼 자리 |
|---|---|---|---|
| **① 로딩 중** | `F12` → Network → `Slow 3G` → 새로고침 | **뼈대(회색 자리표시)** 가 먼저 보이고 내용이 들어올 때 **레이아웃이 안 튄다.** 빈 화면이 잠깐이라도 보이면 안 된다 | `/library/kanji`(1,350자) · `/courses/6/units/1`(한 번에 다 받는다) |
| **② 0개** | 있을 리 없는 말 검색(`zzzzz`) | **"없다"고 말하거나 그 칸이 아예 없다.** 0건이면 **무엇 때문에** 0건인지 되읽어 준다 | `/library/vocabulary`에서 `zzzz` · 나올 수 없는 필터 조합 |
| **③ 1개** | 아주 좁은 조건 | 1개여도 배치가 안 무너진다 | `/library/grammar`에서 정확한 문법 이름 하나 |
| **④ 아주 많음** | 필터를 **전부 풀기** | 쪽 넘김이 있고 마지막 쪽이 빈 쪽이 아니다 | `/library/kanji` 필터 해제 → 마지막 쪽까지 |
| **⑤ 오류** | 주소창에 **이상한 주소** | 무슨 일인지 **말**하고 **나갈 길**이 있다. 하얀 화면이면 결함 | `/courses/99`(없는 코스) · `/courses/2/units/999`(없는 유닛) · `/courses/abc`(숫자 아님) · `/library/kanji?level=E1`(잘못된 조건) — **넷이 서로 다른 종류다** |
| **⑥ 권한 없음** | 로그아웃한 채 직접 입력 | 로그인 화면으로 보내고 **로그인 후 원래 가려던 자리로 돌아온다** | `/mypage` · `/community/write` — 로그인이 필요한 곳은 **이 둘뿐**이다 |

**이 표를 새 화면에도 그대로 옮겨 쓰면 된다.** 새 화면에는 체크리스트가 없다 — 여기서 만든다.

**"없는 것"을 대하는 네 원칙** (`작업자(AI)_문서/08` C-12) — 화면 상태의 판정 기준이다.

| # | 원칙 | 이 사이트에서 | 어기면 |
|---|---|---|---|
| ① | **없는 것을 사과하지 않는다** — 0이 정상인 칸은 **통째로 안 그린다** | 입문 코스에 "한자 0자" 칸이 없고 한자 스텝도 없다 | "한자 0자"가 적혀 있으면 결함 |
| ② | **없는 것을 약속하지 않는다** — "준비 중"류는 **진짜 준비중인 게 있을 때만** | 진단에서 N1을 통과해도 "그 위 코스는 준비 중"이 안 뜬다 | 없는 코스를 약속하면 결함 |
| ③ | **없는 것으로 숫자를 채우지 않는다** — 문항 수는 **배운 재료의 결과**다 | 입문 확인 문제는 6문항이 정상 | 10을 억지로 채웠으면 결함 |
| ④ | **되돌릴 수 없는 실패에 [다시 시도]를 두지 않는다** | 틀린 주소는 통신 실패가 아니다 → 404 + 나갈 길 | `/courses/99`에 [다시 시도]가 있으면 결함 |

**①의 예외를 반드시 기억해라** — **0이 정상이 아닌 칸(문법·어휘·유닛 수)은 0이어도 계속 그린다.**
그 자리의 0은 **콘텐츠가 빠졌다는 신호**다. 숨기면 결함이 안 보이게 된다.
그래서 어떤 칸이 안 보일 때 두 번 묻는다: *여기서 0은 정상인가?* → 정상이면 안 보이는 게 맞다.
*0이 정상이 아닌데 안 보이나?* → **그게 제일 위험한 결함**이다(콘텐츠 누락이 조용히 숨겨진 것).

**상태를 볼 때 늘 함께 보는 것** — ⒜ **레이아웃이 튀는가**(로딩 전후로 버튼이 움직이면 누르려던 순간 다른 게 눌린다)
⒝ **두 번 이상 보이는가**(느리게 해 놓고 보면 같은 내용이 두 번 나타났다 사라지는 화면이 있다 = 두 번 불러오는 것)
⒞ **되돌아오면 그대로인가**(조건 → 상세 → 뒤로. 자료실은 조건을 **주소에 담기** 때문에 살아 있는 게 정상이다).

## 2-4. 불편 찾는 법 — 다섯 가지 자로 재면 나온다

**"안 된다"는 쉽게 찾는다. 어려운 건 "되는데 짜증나는 것"이다.**

**① 손가락 수 세기** — 목표를 정하고 누른 횟수를 센다. **세 번이 넘어가면** 멈춰 서서 "줄일 수 있나?"를 묻는다.
처음 온 사람이 **첫 공부를 시작**하기까지 / 어제 보던 유닛을 **이어서** 보기까지 / 유닛의 한자를 **자료실에서 더 보기**까지(새 탭이 열려 돌아오려면 탭을 닫아야 한다 — **이게 불편의 예다**) /
보관함에 담은 것 **다시 보기**까지(상단 메뉴에 보관함이 없다 — `/bookmarks`를 **주소로 쳐야만** 간다면 사실상 못 가는 것이다).

> 개발자는 주소를 외우고 있어서 늘 1번에 간다. **주소를 모르는 사람에게 그 화면은 없는 화면**이다.
> 그래서 QA는 **"주소를 치지 않고 갈 수 있나"** 를 따로 확인한다.

**② 막다른 길** — 화면에 들어갔으면 반드시 나오는 길이 보여야 한다. **브라우저 뒤로가기는 계산에 넣지 않는다.**
물을 것: 이 화면에서 **다음에 할 일**이 화면 안에 적혀 있나? 실수로 들어왔다면 **어디로 나가나**?
볼 자리: `/courses/99`(버튼이 하나도 없으면 막다른 길) · 확인 문제 끝 · 진단 결과(추천 코스를 **눌러서 갈 수 있나**) ·
`/courses/6/units/25` 정리(N1을 끝낸 사람에게 다음을 말해 주나) · 자료실 0건(조건을 **풀 수 있는 버튼**이 그 자리에 있나).

**③ 되돌리기** — ⒜ 잘못 눌렀다면 되돌릴 수 있나? ⒝ 없다면 **누르기 전에** 알려 주나?
**회원 탈퇴**는 무엇이 지워지는지 먼저 보여주고, **학습 기록 초기화·보관함 비우기**는 되돌릴 수 없다고 미리 말하고, **글 삭제**는 확인을 받아야 한다.
**확인 문제 보기 선택**은 한 번 고르면 못 바꾸는 게 의도된 설계지만, 사용자가 그걸 **미리 아는가**는 확인할 값어치가 있다.
**반대 방향도 본다**: ★(보관함 담기)에 "정말 담을까요?"가 뜨면 그것도 불편이다.

**④ 기다림** — 사람은 0.5초 안에 반응이 없으면 다시 누른다. 반응 없는 구간이 곧 "두 번 눌리는 자리"다.
`Slow 3G`로 바꾸고: 눌렀을 때 **즉시** 뭔가 달라지나? 안 달라지면 **연타해 본다** — 두 번 실행되나?
볼 자리: 로그인 버튼 · **커뮤니티 [등록]**(글이 두 개 올라가면 심각한 결함) · 정리 스텝 완료 토글 · 확인 문제 [문제 풀기] · 자료실 검색.

**⑤ 말이 통하나** — 안내 문구는 셋을 말해야 한다: **무슨 일이 일어났나 / 왜 / 이제 뭘 하면 되나.**
"오류가 발생했습니다"(셋 다 없다 — **무조건 결함**) · "잠시 후 다시 시도"(**얼마나 기다려야 하는지 없다** → 계속 눌러 상황이 악화된다) ·
"결과가 없습니다"(왜 없는지 없다) · "권한이 없습니다"(뭘 하라는 건지 없다).
**확인 방법**: 문구를 볼 때마다 **"그래서 나는 지금 뭘 하면 되지?"** 를 소리 내어 물어라. 답이 화면 안에 없으면 결함이다.

## 2-5. 로직 흔들어 보기 — 규칙대로 해서는 안 보인다

**① 경계 — 틀리는 자리는 언제나 양 끝이다.** 가운데는 잘 돈다.

| 경계 | 흔드는 법 | 무엇을 보나 |
|---|---|---|
| **첫 유닛** | `/courses/2/units/1`에서 [이전] | 유닛 0으로 가려 하면 결함. 버튼이 없거나 안 눌려야 한다 |
| **마지막 유닛 / 마지막 코스** | `/courses/2/units/20` · `/courses/6/units/25` 정리 | 앞은 다음 코스 안내, 뒤는 "준비된 모든 코스를 완주했어요". **"다음 코스 준비중"이 뜨면 결함** |
| **첫 코스** | `/courses/1`(입문) | 한자가 0자인 유일한 코스다. **여기만 다르게 도는 자리가 많다** |
| **부분 공개의 끝** | `/en/courses/102/units/5` 정리 | **완주가 아니라 "열린 데까지의 끝"** 이어야 한다 |
| **문항 0개 근처** | 결과가 **3건**만 나오는 조건으로 [문제 풀기] | 보기 4개를 못 만든다 → "문제를 낼 수 없어요"가 나와야 한다 |
| **최대** | 필터 다 풀고 **마지막 쪽**까지 | 마지막 쪽이 빈 쪽이 아닌가 |
| **입력 길이 양 끝** | 가입 아이디를 **3 / 4 / 20 / 21자** | 4~20자가 규칙이다. **딱 4자와 딱 20자가 통과해야** 한다 |

> **경계 규칙**: 규칙이 "4자 이상"이면 **3·4·5자** 셋을 다 해 본다. 4자만 해 보면 "4자 이상"인지 "5자 이상"인지 구분되지 않는다.

**② 순서 뒤집기** — 사용자는 순서대로 하지 않는다. 주소를 복사해 오고 즐겨찾기로 중간에 들어온다.
유닛 1을 안 보고 **`/courses/2/units/15`** 로 바로 가기(**열린다** — 잠금이 없는 게 설계다) → 그 상태로 코스 상세를 보기(진도·"여기부터" 배지가 **말이 되나**) /
확인 문제를 **먼저** 열고 공부는 안 하기 / 진단 결과 화면 주소로 **직접** 들어가기 / 코스를 거치지 않고 **`/library/kanji/1`** 부터 시작(코스에 **들어갈 길**이 있나).

**③ 두 번 하기** — **무작위가 들어간 자리와 저장이 일어나는 자리는 한 번 성공했다고 넘어가면 안 된다.**
완료 토글을 **빠르게 두 번**(이상한 상태가 되나) / 확인 문제를 같은 유닛에서 **5번 새로** 열기(**한 번이라도 실패하면 결함**) /
자료실 검색 후 [문제 풀기]를 **5번 연속**(§3-C-6) / 뒤로 갔다가 **다시 들어오기** / 같은 ★를 **여러 번** / 로그인 → 로그아웃 → 로그인.

> **무작위가 걸린 자리는 셋이다**: 유닛 **확인 문제**, **자료실 퀴즈**, **실력 진단**. 셋 다 **매번 새로 만든다.**
> **여러 번 돌려 보는 것 말고는 확인할 방법이 없다** — 유닛을 바꿔 가며(1·10·25) 여러 세트를 봐야 한다.

**④ 로그인 전후** — 로그인 없이도 학습이 전부 되므로 "비로그인 → 로그인" 순간이 제일 복잡하다.
시크릿 창에서 ★를 담고 **로그인**(**"계정에 합칠까요?"를 묻는다** — 묻지 않고 자동으로 합치면 결함) / 합치기를 **거절**하고 보관함 보기 /
비로그인으로 유닛 3개 완료 후 로그인(**비로그인 진도는 그 브라우저에만 남는다**는 게 설계다) /
로그인 상태에서 시크릿 창으로 같은 유닛(진도가 섞이면 안 된다) / 로그인한 채 **아주 오래 두었다가** 버튼 누르기(조용히 실패하나).

**⑤ 두 탭** — 사람들은 탭을 여러 개 연다. 특히 자료실 링크가 **새 탭**으로 열려서 더 그렇다.
탭 A에서 ★ 담고 탭 B의 `/bookmarks`를 **새로고침 없이** 보기(안 보이는 게 자연스럽다. 다만 **새로고침하면 반드시 보여야** 한다) /
탭 A에서 유닛 완료 후 탭 B 새로고침 / 탭 A에서 **로그아웃** 후 탭 B에서 마이페이지(에러 화면이 뜨나) /
탭 A에서 비밀번호 변경 후 탭 B에서 계속 쓰기(**다른 기기 로그인이 끊기는 게 설계다** — 조용히 실패하지 않고 말해야 한다) / 두 탭에서 **같은 글을 동시에 수정**.

**⑥ 이 제품 고유의 규칙 — 흔들 거리를 여기서 뽑는다.** 규칙을 알아야 어긴 걸 알아본다.

| 규칙 | 어겼는지 보는 법 |
|---|---|
| 코스는 **입문 → N5 → N4 → N3 → N2 → N1** 한 길 | 코스 목록 순서, 다음 코스 안내가 이 순서를 따르나 |
| **강조 코스 카드는 딱 한 장** · **상단 안내 띠도 항상 하나** | 진도를 여러 코스에 만들어 놓고 `/courses` 보기 |
| 진단은 **한 레벨 = 6문항**, **4개 이상이면 통과** | 정확히 3개면 미달, 4개면 통과인가 |
| 진단 화면·유입 배너가 **총량을 약속하지 않는다** | 소요 시간·판 수·문항 수·"최대"·자동 진행 암시가 **없어야** 한다 |
| 진단 **가장 낮은 레벨에서 떨어지면 입문 추천** | 다 틀리고 결과 보기. N5를 다시 추천하면 결함 |
| 퀴즈 문항은 **최대 10개, 보기는 항상 4개** · 보기는 **같은 레벨에서** 채운다 | 세어 본다. 같은 보기가 있거나 N1 문제에 입문 단어가 섞이면 결함 |
| **입문에는 한자가 0자** | 한자 스텝·한자 칸·한자 문항이 다 없어야 한다 |
| **영어 유닛에는 확인 문제·듣기가 없다** | 있으면 오히려 결함이다(의도적으로 끈 것) |
| 유닛 **잠금이 없다** · 퀴즈·진단 **점수를 저장하지 않는다** | 아무 유닛이나 열리고, 다시 들어가면 처음부터인 게 정상 |
| **어휘 표제어는 표기 + 읽기로 묶인다** | 읽기가 다르면 두 줄, 같으면 한 줄 + 뜻 여러 개(§3-C-12) |

## 2-6. 문서도 QA 대상이다

틀린 문서는 틀린 코드보다 오래 살아남는다 — 아무도 확인하지 않기 때문이다.
**방법은 하나뿐이다: 읽고 판단하지 말고, 손에 들고 사이트에서 그대로 해 보라.** 안 되면 문서가 틀렸다.
문서가 **개수**를 적었으면 세어 보고, **주소**를 적었으면 쳐 보고, **상태**를 적었으면 그 화면을 열고,
**"할 예정"** 이라고 적었으면 **이미 돼 있는지** 보고, **"반영처"** 를 적었으면 그 파일을 **열어 본다**
(없는 곳을 가리키는 문서는 **착지하지 않은 결정**이다 — 다음 사람이 잘못된 파일을 고친다).

**다섯 질문** — ⒜ 숫자를 세어 봤나 ⒝ 주소를 쳐 봤나 ⒞ "할 예정"인데 이미 된 것이 있나
⒟ **이 문서가 자기 자신과 어긋나나** ⒠ 다른 문서가 같은 것을 다르게 말하나

> **지난 경험에서 남는 교훈 둘** (사례 자체는 다 해소돼 지웠다)
> - **문서는 같은 문서 안에서도 서로 어긋날 수 있다.** 목록 표와 본문 서술이 다르면 대개 **한쪽을 고치고 다른 쪽을 잊은 것**이다 — 그 자리를 찾아라.
> - **두 화면이 같은 사실을 다르게 말하는 자리**도 같은 종류의 결함이다(코스 상세는 "채우는 중"인데 유닛 정리는 "완주"라고 말하는 것).

**발견하면**: 고치는 건 담당자의 일이다. QA는 **"문서 A의 몇 절이 X라고 적었는데 실제는 Y"** 로 적어 넘긴다.
**실물이 사실이다** — 문서 쪽을 고친다. (다만 "실물이 틀린 것"일 가능성도 한 번은 의심한다. 문서가 원래 의도였고 코드가 이탈했을 수도 있다.)

## 2-7. 체크리스트를 다 썼을 때 — 화면 하나에 여섯 질문

**질문 하나당 확인거리가 최소 하나씩 나온다.** 화면이 27개니까 160개가 나온다.

| # | 질문 | `/bookmarks`에 대입한 예 |
|---|---|---|
| ① | 여기에 **아무것도 없을 때** 어떻게 보이나? | 아무것도 안 담은 사람이 열면? 3탭 중 한 탭만 비면? |
| ② | 여기에 **너무 많을 때** 어떻게 보이나? | 비로그인 상한인 **200개**를 담으면? 201개째는? |
| ③ | 여기까지 **주소를 모르고** 올 수 있나? | 상단 메뉴에 보관함이 없다 → 어디서 들어가나? |
| ④ | 여기서 **나갈 길**이 있나? | 비었을 때 "자료실 가서 담아 보세요" 같은 길이 있나? |
| ⑤ | 여기서 **되돌릴 수 없는 것**이 있나? | [비우기]. 확인을 받나? |
| ⑥ | 여기가 **로그인 전후로** 달라지나? | 비로그인은 브라우저에만 저장 → 로그인하면 합치기를 묻나? |

> **한 걸음 더**: 여섯에 답하고 나면 각 답에 **"그럼 그때 사용자는 뭘 하지?"** 를 한 번 더 묻는다.
> 이 되묻기가 §2-4(불편 찾기)로 이어진다. 여기서 나온 것이 **체크리스트에 없는 새 결함**이다.

# §3. 체크리스트

**어디부터 보는 게 이득인가** — 시간은 늘 모자란다. 순서를 잘못 잡으면 시간을 다 쓰고도 중요한 걸 못 본다.
**1순위 최근에 바뀐 곳**(결함의 대부분은 방금 손댄 자리에서 나온다) → **2순위 계정 관련**(로그인·비밀번호·탈퇴·남의 글 — 깨지면 한 사람의 피해가 크다)
→ **3순위 되돌릴 수 없는 것**(탈퇴·삭제·초기화) → **핵심 흐름**(처음 온 사람이 유닛 하나를 끝내는 길) → **부가 화면**(커뮤니티).
**지금 1순위가 어디인지**는 `README.md`의 "현재 상태·다음 순서"와 `현재_기능현황.md`의 최근 날짜가 붙은 절을 본다.

**30분 코스 — 시간이 없을 때.** 목표: **크게 망가진 게 없는지 확인.** 자잘한 불편은 포기한다.
하나라도 걸리면 **거기서 멈추고 리포트한다**(다음 항목은 그 결함 때문에 안 될 수도 있다).

| 시간 | 무엇 | 보는 눈 |
|---|---|---|
| 0~3분 | 홈 → `/courses` → 코스 하나 | 화면이 뜨나. 코스 **6장**이고 일본어에 준비중이 없나 |
| 3~10분 | 유닛 하나를 **끝까지**(`/courses/2/units/1`) → 정리 → 확인 문제 | **핵심 흐름 한 바퀴.** 여기가 막히면 나머지는 볼 필요도 없다 |
| 10~15분 | 코스 상세의 **✓ 완료**·"여기부터" → 나갔다 다시 들어오기 | **저장이 되는가.** 저장 안 되는 학습 사이트는 쓸모가 없다 |
| 15~20분 | `/library/kanji` 검색·필터 → 새로고침 | 조건이 **주소에 남아 살아나는가** |
| 20~25분 | `/courses/99` · `/courses/2/units/999` · `/없는주소` | 하얀 화면이 아니라 **안내 + 나갈 길** |
| 25~30분 | 로그아웃 상태로 `/mypage` → 로그인 → 다시 | **권한 흐름**이 도는가 |

**2시간 코스 — 제대로 볼 때.** 30분 코스는 "안 망가졌나"고, 이건 **"뭐가 이상한가"** 다.

| 시간 | 무엇 | 렌즈 |
|---|---|---|
| 0~15분 | 30분 코스를 압축해 한 바퀴 | — |
| 15~35분 | **상태 여섯 개**를 자료실·유닛 학습·코스 상세에 대입 | §2-3 |
| 35~55분 | **경계 흔들기** — 첫/마지막 유닛, 입문 코스, N1 마지막, **E2 유닛 5**, 입력 길이 양 끝 | §2-5 ① |
| 55~75분 | **순서 뒤집기 + 두 번 하기** — 중간 유닛부터, 완료 연타, 퀴즈 5회 | §2-5 ②③ |
| 75~90분 | **로그인 전후 + 두 탭** | §2-5 ④⑤ |
| 90~105분 | **불편 찾기** — 손가락 수, 막다른 길, 안내 문구 | §2-4 |
| 105~120분 | **문서 대조** — §1을 손에 들고 실제와 대조 | §2-6 |

> 아래 **A→B→C를 순서대로 하면 30~40분**이다. 시간이 없으면 **C만** 해도 값어치가 있다.
> "정상이면 이렇게 보인다"의 근거는 §1이다 — 체크리스트는 그걸 되풀어 적지 않고 **할 일만** 적는다.

### A. 첫 5분 — 사이트가 살아 있는가

- [ ] `http://localhost:8103` → **홈**이 뜬다. 빈 화면·에러 문구가 없다.
- [ ] 홈에 히어로 + **진단 안내 띠** + 강점 카드 3장 + 수치 + 유닛 흐름 6단계가 있고 **코스 카드는 없다.**
- [ ] 홈 수치가 **코스 6개 · 유닛 125개 · 한자 1,350자 · 문법 295개 · 어휘 1,734개**다.
- [ ] 상단 메뉴가 **학습 · 자료실 · 커뮤니티 3개**다(채팅 없음). **일본어/영어 스위처**가 있고 "일본어"가 켜져 있다.
- [ ] 밝게/어둡게 → 바뀌고 새로고침해도 유지된다. 화면 폭을 좁히면 **햄버거**로 접히고 열면 메뉴·스위처가 다 나온다.
- [ ] `localhost:8103/없는주소` → **404 안내 화면**(하얀 화면이 아니다).

### B. 학습 한 바퀴 — 실제로 공부해 본다 (핵심)

**B-1. 코스 목록 → 코스 상세**

- [ ] `/courses`에 코스가 **입문 → 왕초보 → 초급 → 중급 → 중상급 → 고급** 순서로 6장.
- [ ] 상단 안내 띠가 **딱 하나**이고 **[내 시작점 찾기]** 버튼이 있다.
- [ ] 아직 아무것도 안 배웠다면 **입문 카드에만 "여기서 시작하세요"**(강조 카드는 한 장뿐).
- [ ] 입문 카드 → **유닛 10개**. 집계 줄이 `유닛 10 · 문법 20 · 어휘 150개`처럼 **한자 칸 없이** 나온다.

**B-2. 유닛 학습 (`/courses/2/units/1`)**

- [ ] 문법 → 회화(**전체 듣기** 눌러 소리가 난다. 컴퓨터에 일본어 음성이 없으면 **버튼 자체가 안 보이는 것**이 정상)
      → 한자 → 어휘 스텝이 §1-1 표대로 나온다.
- [ ] 스텝 칩 중 아무거나 눌러 **건너뛴다** → 막히지 않는다. 스텝을 바꾸면 화면이 **맨 위로** 올라간다.
- [ ] 어휘에서 **[다음 ›]** → **확인 문제**다(정리가 아니다). 한 번 더 → **정리**.
- [ ] **정리** → 요약 + **완료 표시가 켜진다.** [다음 유닛 ›]은 **이 스텝에만** 있다.
- [ ] 뒤로 나갔다 같은 유닛에 다시 → **보던 스텝**으로 돌아온다.
- [ ] 코스 상세 → 유닛 1에 **✓ 완료**, 유닛 2에 **여기부터** 배지.

**B-3. 확인 문제**

- [ ] 확인 문제 스텝 → 문제가 생성된다("만들 수 없다"가 아니다). 문항 **10개 이하**, 보기 **4개**.
- [ ] 보기를 누르면 **즉시** 채점되고 답을 바꿀 수 없다.
- [ ] 끝까지 풀면 점수 + **[틀린 문제만 다시 풀기]** → **아까 틀린 그 문제 그대로**. 틀린 문항의 자료실 링크도 눌러 본다.
- [ ] `/courses/1/units/1`(입문) → **6문항이면 정상**이다.

**B-4. 자료실**

- [ ] 메뉴 [자료실] → `/library/kanji`, **한 쪽에 60자**.
- [ ] 검색창에 `학` → 결과가 줄고 **주소가 바뀐다.** 새로고침해도 유지된다.
- [ ] 레벨 필터 N3만 → **적용된 조건 칩**이 뜨고 X로 하나씩 뺄 수 있다.
- [ ] 나올 것이 없는 조건 → **무엇 때문에 0건인지** 문장으로 설명해 준다.
- [ ] 문법 탭(**20개/쪽**, "활용표 있는 것만" 켜면 **87개**) · 어휘 탭(**50개/쪽**, 줄을 누르면 **그 자리에서 펼쳐진다**).
- [ ] 한자 상세의 "어디서 배우나" 링크 → 그 유닛 학습 화면으로 간다.
- [ ] 레벨 선택지가 **6개**인데 **한자 탭만 입문이 빠져 5개**다.
- [ ] 개수 줄의 **[이 조건으로 문제 풀기]** → 범위를 되읽어 주는 화면 → **10 / 20문제** 고르고 [문제 풀기] → 문제가 나온다.

**B-5. 실력 진단** — 정상 동작의 근거는 §1-3이다. 여기서는 **흔드는 것만** 한다.

- [ ] 홈이나 코스 목록의 **[내 시작점 찾기]** 로 들어간다(상단 메뉴에 진단이 **없는 것**이 정상).
- [ ] 레벨 6개가 낮은 것부터 있고 **입문이 이미 골라져 있다.** ★ **소요 시간·판 수·문항 수·"최대 n단계"를 약속하는 말이 없다.**
      *(이 금지는 진단 화면과 유입 배너 세 곳 모두 자동 테스트가 잡는다 — 사람은 "표현이 자연스러운가"만 보면 된다.)*
- [ ] [시작하기] → `문자 레벨 · 6문항` + 6문항이 **한 화면에**. 머리글에 개수가 안 붙고 번호는 1~6. 보기는 **5개**, 맨 아래가 **[모르겠어요]**.
- [ ] 두어 문항을 **비워 둔 채** 제출 → **결과가 나오지 않고** 화면이 **번호가 가장 작은 빈 문항**으로 올라가며 커서가 그 보기에 놓인다.
- [ ] 빈 문항 **전부**에 안내 줄이 붙어 있다(첫 문항에만 붙는 게 아니다). 누르기 **전에는** 하나도 없었다.
- [ ] 버튼이 **회색이 아니다.** 막힌 뒤에도 답을 **바꿀 수 있고**, 여러 번 눌러도 매번 첫 빈 문항으로 갈 뿐이다. 모달도 없다.
- [ ] 한 칸 채우면 **그 줄만 즉시 사라진다.** 다 채우고 다시 누르면 **그제서야** 결과다. 판정표에 그 레벨 줄이 **하나**다(막힌 시도는 기록 안 됨).
- [ ] 키보드만으로도 된다: 제출에서 Enter → 막히면 커서가 그 문항 보기에 있어 **화살표만으로 답을 고를 수 있다.**
- [ ] *(한 판 더)* 6문항 **전부 [모르겠어요]** → 막히지 않고 제출되고 **0 / 6 미달**. **[모르겠어요]는 답이다.**
- [ ] [다른 레벨 고르기] → 방금 친 레벨 옆에 **`· 4 / 6`** 이 붙어 있고 기본 선택은 다시 입문이다.
- [ ] **고급(N1)** 을 골라 시작 → N1 문항이 **바로** 나온다. 머리글이 `어휘`·`어법` 둘뿐이고 보기까지 전부 일본어다.
- [ ] 같은 레벨을 두 번 치면 판정표 줄이 **하나**이고 나중 결과로 바뀐다. 판정표는 친 순서가 아니라 **레벨 순**이다.
- [ ] 결과 화면에서 **새로고침** → 레벨 고르기로 돌아가고 판정표가 **모두 사라진다.** ⚠️ **자동 테스트가 없어 반드시 손으로 본다.**

**B-6. 보관함**

- [ ] 자료실이나 유닛 학습에서 **★** 를 몇 개 → `/bookmarks`에서 **한자·문법·어휘 3탭**에 들어가 있다. 다시 누르면 빠진다.
- [ ] 유닛 학습에서 문법 옆 ★ → **자료실로 이동하지 않고** 별만 켜진다.

**B-7. 영어 과정** — 코스가 **둘** 열려 있고, 둘이 **서로 다른 끝**을 보여주는 쌍이다.

- [ ] 스위처에서 **영어** → `/en/courses`. 코스 5장 중 **2장 열림 / 3장(E3·E4·E5) 준비중**. 준비중 카드는 안 움직이거나 안내 화면으로 간다.
- [ ] **E1 카드에 `✎` 안내 문구가 없다.** **E2 카드에는 `✎` 채우는 중 안내 한 줄이 있다.**
- [ ] **E1 상세(`/en/courses/101`)**: 유닛 **15개**, 맨 위에 **`✎` 안내 띠가 없다**(한 줄이라도 있으면 결함).
- [ ] **E2 상세(`/en/courses/102`)**: 유닛 **5개**(계획 20이 아니다), 맨 위에 **`✎` 채우는 중 안내 띠가 있다**(없으면 결함).
- [ ] 유닛 1 → **표현 스텝**이 있고 발음 표기가 붙어 있다. **확인 문제 스텝도 듣기 버튼도 없다.**
- [ ] **E1 유닛 5·10·15 정리** → 각각 **복습 블록**(1~5 / 6~10 / 11~15). 유닛 4·9·14 정리에는 **없다.**
- [ ] **E1 유닛 15 정리** → **완주 안내**. E2가 열려 있으므로 **다음 코스로 바로 이어갈 수 있다는 안내 + 버튼**이 함께 나온다.
      "여기까지가 지금 열려 있는 마지막 유닛이에요"가 뜨면 **결함**.
- [ ] **E2 유닛 5 정리** → **복습 블록 1~5** + **"열린 데까지의 끝" 중립 안내**. **완주 축하(🎉)가 뜨면 결함**이고, 둘은 **동시에 뜨지 않는다.**
- [ ] 그 안내가 **E2 코스 상세의 `✎` 안내와 같은 말**을 하는가(같은 사실을 두 화면이 다르게 말하면 결함이다).
- [ ] `/en/courses/102/units/6` → **없는 주소** 안내(아직 안 열린 유닛이다).
- [ ] `/en/start` → 문장을 고르면 코스로 보내 준다.

**B-8. 계정·커뮤니티**

- [ ] 로그인 안 한 채 `/mypage` → **로그인 화면**. `user4`/`1234`로 로그인 → 상단에 닉네임·마이페이지.
- [ ] 프로필 수정에서 닉네임을 바꾸면 상단 표시도 바뀐다. 로그아웃 → 홈 + [로그인].
- [ ] 로그인 안 한 채 `/community` 목록·상세가 잘 보인다. 로그인하고 글을 쓰면 목록에 올라오고 **내 글에 수정·삭제**가 있다.

**B-9. 뒤로가기·새로고침** (§1-6과 짝)

- [ ] `/community` 목록을 **한참 내린 뒤** 글을 연다 → 뒤로 → **보던 자리**로 돌아오고 **"로딩 중"이 안 뜬다.**
- [ ] 코스 목록 → 상세 → 뒤로 → 다시 상세 → **회색 뼈대 없이 바로** 내용이 보인다.
- [ ] 반대로 링크를 눌러 **새 화면으로 갈 때는 맨 위**에서 시작한다.
- [ ] 자료실에서 **쪽을 넘긴다** → 사라졌다 나타나지 않고 **흐려졌다 갈아끼워진다.**
- [ ] 댓글이 여러 쪽인 글에서 **2쪽** → 주소 끝에 `?cpage=` 가 붙고 **새로고침해도 그 쪽**. 1쪽으로 오면 사라진다.
- [ ] 글을 **수정하거나 지운 뒤** 목록으로 → 옛 제목이 남아 있지 않다.
- [ ] `/diagnosis` 결과에서 **새로고침** → 레벨 고르기로 돌아가는 것이 **정상**(진단만 예외).

### C. 되돌아왔는지 확인 — 예전에 고쳤던 것들 ★이 문서에서 가장 값나가는 절

> 아래는 실제로 발견돼 **고친** 것들이다. 다시 나타나면 안 된다. **다른 건 못 하더라도 이건 하자.**
>
> **「테스트」가 ✅ 인 항목은 자동 테스트가 이미 잡는다** — 사람이 중복으로 볼 필요가 없다.
> 그중에도 손으로 볼 값어치가 남은 것은 괄호에 이유를 적었다(대개 "무작위라 한 번으로는 모른다").
> **⬜ 인 항목이 사람이 반드시 봐야 하는 것**이다.

| # | 확인 | 정상이면 | 테스트 |
|---|---|---|:---:|
| C-1 | 영어 화면에서 상단 **[자료실]** 누르기 | **영어 표현 자료실**(`/en/library/expressions`)로 간다. 일본어 한자 목록이 나오면 결함 | ✅ |
| C-2 | 영어 유닛 학습 화면 훑어보기 | **확인 문제 스텝도, 듣기 버튼도 없다**(일부러 끈 것 — 있으면 오히려 결함) | ✅ |
| C-3 | 입문 코스(`/courses/1`) 집계 줄과 유닛 줄·스텝 칩 | **"한자 0자"라는 칸이 아예 없고** 스텝 칩에 "한자"가 없다 | ✅ |
| C-4 | 진단에서 입문 6문항 전부 [모르겠어요]로 제출 | 추천이 **입문**이다(N5가 아니다). 아래로 가는 버튼이 **없다**(비활성 버튼도 없다) | ✅ |
| C-5 | N1 유닛(`/courses/6/units/1`) 확인 문제 보기 | 보기가 전부 N1급. **입문 인사말이 섞이면 결함** | ✅ (무작위 — 아래 요령대로 손으로도) |
| C-6 | 어휘 자료실에서 `하` 검색 → 퀴즈 **5번 연속** 열기 | **매번 문제가 나온다** | ✅ (무작위 — 아래 요령대로 손으로도) |
| C-7 | 남의 글을 다른 계정·비로그인으로 보기 | **수정·삭제 버튼이 안 보인다**(남의 댓글에도) | ✅ |
| C-8 | 로그인 비밀번호를 **5번 틀리기** | **"15분 뒤에 다시 시도"** — 얼마나 기다리는지 말해 준다 | ✅ (아래 ⚠️ 주의) |
| C-9 | 영어 유닛 공부한 뒤 마이페이지 [이어서 학습하기] | **영어 유닛으로 제대로 간다**(404도, 엉뚱한 일본어 코스도 아니다) | ✅ |
| C-10 | 진단에서 고급(N1)을 골라 통과하기 | **"그 위 코스는 준비 중"이 안 뜬다.** 위로 가는 버튼이 없다 | ✅ |
| C-11 | 진단에서 중상급(N2)만 골라 통과하기 | 추천이 **고급(N1) 코스**다(왕초보 N5가 아니다) | ✅ |
| C-12 | 영어 어휘 자료실에서 `close` · `leave` 검색 | `close`는 **두 줄**, `leave`는 **한 줄 + 뜻 2개**(아래 요령) | ✅ |
| C-13 | **E2 유닛 5 정리** vs **E1 유닛 15 정리** | 앞은 **열린 끝**, 뒤는 **완주**. 바뀌어 있으면 결함 | ✅ |
| C-14 | 진단 유입 배너·진단 화면의 문구 | **총량(시간·판 수·문항 수)을 약속하지 않는다** | ✅ |
| C-15 | 홈(`/`)을 열어 본다 | **코스 카드가 늘어서 있지 않다** — 홈과 코스 목록이 같은 화면이 되지 않는다 | ⬜ |
| C-16 | 진단 결과 화면에서 **새로고침** | 레벨 고르기로 돌아가고 판정표가 비워진다 | ⬜ |

**손으로 볼 때의 요령 — 길어지는 넷만 적는다.**

**C-5 (무작위)** `/courses/6/units/1` → 확인 문제. 문항마다 **보기 4개**를 하나하나 읽는다.
`おはようございます` 같은 입문 인사말이 섞이면 결함이다 — 그러면 문제가 "뜻 맞히기"가 아니라 "쉬운 것 고르기"가 된다.
**여러 유닛(1·10·25)에서 몇 세트 반복** — 매번 새로 만들기 때문이다.

**C-6 (무작위)** `/library/vocabulary`에서 **`하`** 검색 → **[이 조건으로 문제 풀기]** → 뒤로 → **같은 동작 5번 반복**.
한 번이라도 "이 조건으로는 문제를 낼 수 없어요"가 뜨면 결함이다. **예전에 절반 확률로** 실패하던 자리다 — 한 번 성공했다고 넘어가지 말자.

**C-8** ⚠️ **진짜로 15분 잠긴다.** 반드시 **테스트 계정(`user12` 등)** 으로 하고 평소 쓰는 계정으로는 하지 말자.
`/login`에서 틀린 비밀번호로 5번 연속 → **"로그인 시도가 너무 많아요. 15분 뒤에 다시 시도할 수 있어요."**
"잠시 후 다시 시도"처럼 **얼마나 기다려야 하는지 안 알려주면** 결함이다(계속 눌러 잠금이 늘어난다).

**C-12 — 둘이 서로를 가르는 쌍이다. 반드시 함께 한다.**
`/en/library/vocabulary`에서 **`close`** → **두 줄**(`/kloʊs/` 가까운 · `/kloʊz/` 닫다). 한 줄로 뭉개져 있으면 결함이다 —
발음을 배우러 온 화면이 발음을 틀리게 알려 주게 된다. 이어서 **`leave`** → **한 줄 + 뜻 2개**(떠나다 / 남기다). 발음이 같으니 같은 단어다.
두 줄로 갈려 있으면 결함이다. **하나만 보면 반대 방향으로 틀린 구현이 통과한다.**

### D. 여유가 있으면 — 흔들어 보기

- [ ] 유닛 학습 중 **인터넷을 잠깐 끊고** 새로고침 → 에러 안내 카드 + **[다시 시도]**(하얀 화면이 아니다).
- [ ] `/courses/99` · `/courses/abc` · `/courses/2/units/999` → 모두 **없는 주소 안내**.
      ⚠️ **셋 다 [다시 시도]가 있으면 안 된다** — 눌러도 영원히 같은 실패다.
- [ ] 자료실 주소 끝에 `?level=INTRO` + **한자** 탭 → 에러가 아니라 **0건**이고 칩에서 뺄 수 있다.
- [ ] 자료실 주소 끝에 `?level=E1` → **"지원하지 않는 레벨입니다"** 안내.
- [ ] 시크릿 창에서 ★를 담고 `/bookmarks` → **로그인 없이도 잘 보인다** → 그 창에서 로그인 → **"합칠까요?" 띠**(묻지도 않고 합치면 결함).
- [ ] 유닛 학습 주소를 복사해 **시크릿 창**에 → 같은 화면이 그대로 열린다.
- [ ] 커뮤니티 글쓰기에서 **10MB 넘는 파일** → 안내가 나온다(그냥 멈추면 결함).

### E. 배포 직전에 추가로

- [ ] **A·B·C 전체**를 한 바퀴.
- [ ] **편집 모드 띠가 사라졌는지** — 올린 사이트에는 없는 게 정상이다(켜져 있으면 기동을 거부해야 한다).
- [ ] 콘텐츠(코스·자료실)가 **비어 보이지 않는지** — 비면 운영 시드 적재가 빠진 것이다.
- [ ] 로그인·회원가입이 **실제로 되는지** — 로컬에서 됐다고 운영에서 된다는 보장은 QA로만 확인한다.

# §4. 발견한 걸 어떻게 적나

**한 줄로 "안 돼요"라고 하면 고치는 데 하루가 걸리고, 아래 네 개를 적어 주면 30분이면 된다.**

| 칸 | 적는 것 |
|---|---|
| **① 재현 절차** | **주소 + 누른 순서.** 다른 사람이 그대로 따라 해서 같은 걸 볼 수 있어야 한다 |
| **② 기대** | **왜 그게 맞다고 생각했는지.** 근거 문서(§1의 어느 절)가 있으면 함께 |
| **③ 실제** | 눈에 **보인 그대로.** 해석하지 말고 적는다 |
| **④ 심각도** | 아래 기준으로. **매기지 않고 넘기면 받는 쪽이 순서를 못 정한다** |

**함께 있으면 훨씬 좋은 것** — **몇 번 만에 나왔는지**("한 번에" / "5번 중 2번" / "매번" — **무작위가 걸린 화면에서는 이게 결정적**) ·
**스크린샷**(`Windows + Shift + S`, **주소창이 함께 찍히면 최고**) · **로그인 상태** · **창 크기** · **콘솔 빨간 줄의 첫 줄**.

```
주소: localhost:8103/mypage
순서: user4로 로그인 → 영어 유닛 1 보다가 → 마이페이지 → [이어서 학습하기] 클릭
기대: 보던 영어 유닛으로 돌아감 (§1-5)
실제: "없는 주소입니다" 화면이 떴음
빈도: 3번 중 3번 (매번)
화면: 노트북, 로그인 상태
심각도: 높음
(스크린샷 첨부)
```

**심각도는 세 가지를 물어서 정한다** — "얼마나 화나는가"가 아니다.
⒜ **모두 겪나?** 모두 → 올라간다 ⒝ **우회로가 있나?** 없다 → 올라간다 ⒞ **데이터가 망가지나?** → **무조건 최고**

| 심각도 | 조건 | 예 |
|---|---|---|
| **치명** | 데이터가 망가진다 / 남의 것이 보인다 / 사이트가 안 뜬다 | 남의 글에 **수정·삭제 버튼이 보인다** · 진도가 남의 것과 섞인다 · 홈이 하얀 화면 |
| **높음** | 모두 겪고 우회로가 없다 | 확인 문제가 **안 만들어진다** · 유닛 완료가 저장되지 않는다 · [이어서 학습하기]가 404 |
| **보통** | 모두 겪지만 우회로가 있다 / 일부만 겪고 우회로가 없다 | 자료실 조건이 새로고침하면 풀린다 · 특정 코스에서만 집계가 틀리다 |
| **낮음** | 일부만 겪고 우회로도 있다 | 안내 문구가 어색하다 · 탭이 계속 쌓인다 · 빈 상자가 하나 남는다 |

> **"낮음"도 적어서 넘긴다.** 고칠지 말지는 남이 정한다. **QA는 판단을 하지 말고 사실과 근거를 준다.**

**결함이 아닌 것 — 신고 전에 여기부터 본다.** 전부 의도된 동작이다. 모르고 신고하면 신뢰가 깎이고 진짜 결함이 묻힌다.

- 입문 코스에 한자가 없고 확인 문제가 **6문항**인 것
- 영어 유닛에 **확인 문제·듣기 버튼이 없는** 것 / 컴퓨터에 일본어 음성이 없어 **듣기 버튼 자체가 안 보이는** 것
- 퀴즈·진단 **점수가 저장되지 않는** 것(오답 노트·통계는 만들지 않기로 확정). 진단 판정표도 새로고침하면 비워진다
- 진단에서 통과해도 **다음 레벨이 자동으로 뜨지 않는** 것 / **[끝내기] 버튼이 없는** 것(안 누르면 그게 끝내기다)
- 진단에서 **빈 문항이 있으면 제출이 안 되고** 그 문항으로 올라가는 것 — [모르겠어요]가 이미 있으니 빈칸은 실수로 본다.
  그때 제출 버튼이 **회색으로 바뀌지 않는** 것도 의도다(눌러야 "어디를 채워야 하는지"를 알려줄 수 있다)
- 진단 N2·N1 문항에 질문 줄이 없고 머리글만 있는 것 / 입문·N5에 한자·가타카나가 안 나오는 것 (레벨별 표기 규칙)
- 유닛에서 **확인 문제가 정리보다 앞**에 오는 것 ([다음 ›]만 눌러도 문제를 만나게 하려고 옮긴 자리)
- 뒤로 돌아왔을 때 **로딩 없이 바로 내용이 보이고** 잠시 뒤 슬쩍 갱신되는 것
- 유닛 순서가 **강제되지 않는** 것 / 아이디·비밀번호 **찾기 화면이 없는** 것 / 진단이 **상단 메뉴에 없는** 것
- 자료실 링크가 **새 탭**으로 열리는 것(같은 탭으로 바꾸는 건 다음 과제)
- 문법 295개 중 **활용표가 87개에만** 있는 것 / 어휘 자료실에 **상세 화면이 없고** 줄이 펼쳐지는 것
- **E2 유닛 5가 완주가 아닌** 것(계획 20 중 5만 열렸다 — 채우면 저절로 완주로 바뀐다)
- 마지막 위치가 **일본어·영어 공용 한 칸**인 것("지금 있는 곳"은 사람마다 하나다)

> **판단이 안 서면 신고해라.** 단 **"이게 의도인지 모르겠다"** 를 함께 적어라. 그 자체가 리포트감이다 —
> **QA가 판단 못 하는 화면은 사용자도 판단 못 한다.**
