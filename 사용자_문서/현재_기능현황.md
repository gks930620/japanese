## 2. 코스와 콘텐츠

### 2-1. 일본어 — 6코스 전부 공개

| 코스 | 레벨 | 제목 | 유닛 |
|---:|---|---|---:|
| 1 | 문자 | 입문 | 10 |
| 2 | JLPT N5 | 왕초보 | 20 |
| 3 | JLPT N4 | 초급 | 20 |
| 4 | JLPT N3 | 중급 | 25 |
| 5 | JLPT N2 | 중상급 | 25 |
| 6 | JLPT N1 | 고급 | 25 |

**유닛 1개 = 문법 2~3 + 그 문법이 쓰인 회화 1편 + 한자 0~14자 + 어휘 15~20 + 확인 문제 + 정리.**

### 2-2. 영어 — 2코스 공개

| 코스 | 레벨 | 제목 | 상태 | 유닛(열림/계획) |
|---:|---|---|---|---:|
| 101 | E1 | 다시 세우기 | **공개 · 완성** | **15** / 15 |
| 102 | E2 | 일상 말하기 | **공개 · 채우는 중** | **10** / 20 |
| 103 | E3 | 이어 말하기 | 준비중 | 0 / 20 |
| 104 | E4 | 뉘앙스 | 준비중 | 0 / 20 |
| 105 | E5 | 실전과 격식 | 준비중 | 0 / 20 |

**영어 유닛은 세 번째 자리가 한자가 아니라 「표현」**(구동사·연어·관용)이다. 한자는 0행이고, **확인 문제·음성은 의도적으로 없다.**
E2는 **계획 20 중 10만 열려 있어**, 유닛 10의 정리가 "완주"가 아니라 **"열린 데까지의 끝"** 으로 뜨고 코스 상세에 채우는 중이라는 안내가 붙는다.

### 2-3. 자료실 총량 (= 코스에 들어간 데이터를 사전처럼 다시 보여주는 뷰)

| | 일본어 | 영어 |
|---|---:|---:|
| 한자 | **1,350** | — (영어엔 한자가 없다) |
| 문법 | **295** | **72** |
| 표현 | — | **173** |
| 어휘(표제어) | **1,734** | **390** |

- 콘텐츠는 **페이지가 아니라 DB 데이터**다. 코스·유닛은 그 데이터를 참조하는 얇은 매핑 층(플레이리스트 모델)이고,
  **매핑되지 않은 고아 행은 0건**이다.
- 어휘는 **표기 + 읽기**로 묶인 표제어 수다(일본어는 `kana`, 영어는 `ipa`가 읽기).
  그래서 영어 시드 398행이 표제어 **390**이 된다 — `leave`(떠나다 / 남기다)가 발음이 같아 한 줄로 묶이고,
  `close`(`/kloʊs/` 가까운 / `/kloʊz/` 닫다)는 발음이 달라 두 줄로 갈린다.
- 문법 **295개 중 87개**가 활용 규칙표를 갖고 있다. 나머지 208개는 `rules: []`이고 **서술형 문법은 없는 게 정상**이다.

## 3. 학습 화면

- **유닛 학습**: 문법 → 회화 → 한자(영어는 표현) → 어휘 → 확인 문제 → 정리 순으로 스텝을 넘긴다. 정리에서 완료로 켜지고 다음 유닛으로 이어진다.
- **5의 배수 유닛(5·10·15·20·25)의 정리에 복습 블록**이 붙는다 — 직전 5유닛 분량을 모아 보여준다.
- **코스의 끝은 세 종류**다: 완주 + 다음 코스 있음 / 완주 + 다음 코스 준비중 / **열린 데까지의 끝**(계획보다 적게 열린 코스).
  판정은 사람이 켜는 플래그가 아니라 **개수 비교**(`totalUnits` vs `coursePlannedUnits`)라, 계획을 채우면 저절로 완주로 바뀐다.
- **일본어 문장은 3줄 병기**(원문 / 읽는 법 / 뜻). 영어는 읽는 법 자리에 **IPA + 한글 근사 표기**가 온다.

## 4. 학습 도구

| 도구 | 지금 상태 |
|---|---|
| **확인 문제** | 유닛 콘텐츠로 **매번 새로 생성**하는 4지선다(최대 10문항). **일본어에만 있다** |
| **자료실 퀴즈** | 자료실 목록이 보여준 범위가 그대로 출제 범위가 된다 |
| **실력 진단** (`/diagnosis`) | **레벨을 직접 골라** 한 판(6문항)씩 친다. 통과든 미달이든 **결과 화면에서 멈춘다** — 자동으로 다음 레벨로 올라가지 않는다. [모르겠어요] 보기가 있고, **미응답이 있으면 제출되지 않는다**(누르면 첫 빈 문항으로 데려간다). 결과를 저장하지 않는다 |
| **영어 시작점 안내** (`/en/start`) | 문제·채점이 **없다.** "지금 무엇을 말할 수 있는가" 문장을 고르면 그 코스로 보낸다 |
| **음성(TTS)** | 브라우저 음성으로 일본어 문장·회화를 읽는다. [느리게] · [전체 재생]. **영어에는 없다** |

## 8. 이 수치를 다시 재는 법

문서에서 베끼지 말고 **아래를 돌려라.** 서버는 `java -jar`로 띄운다(`gradlew bootRun`은 테스트를 돌리면 죽는다 — `../작업자(AI)_문서/02 §5-1`).

```bash
# 코스·유닛
curl -s localhost:8103/api/courses        # 일본어 6개
curl -s localhost:8103/api/en/courses     # 영어 5개

# 자료실 총량 (totalAll)
curl -s "localhost:8103/api/library/kanji?size=1"
curl -s "localhost:8103/api/library/grammar?size=1"
curl -s "localhost:8103/api/library/vocabulary?size=1"
curl -s "localhost:8103/api/en/library/grammar?size=1"
curl -s "localhost:8103/api/en/library/expressions?size=1"
curl -s "localhost:8103/api/en/library/vocabulary?size=1"

# 화면·API·테스트
grep -c "<Route" frontend/src/App.jsx
grep -rhoE "@(Get|Post|Put|Patch|Delete)Mapping" --include=*.java src/main/java | sort | uniq -c
find src/test -name "*Test.java" | wc -l
find frontend/src -name "*.test.js*" | wc -l
```

> ⚠️ **시드 SQL을 눈으로 세지 마라.** id가 테이블마다 겹쳐서(어휘 9330과 문법예문 9330은 다른 행이다) 엉뚱한 행을 센다.
> 값 묶음을 `(숫자, ` 정규식으로 세면 **주석 줄까지 걸린다.** 응답으로 세면 **"만든 것"이 아니라 "학습자가 실제로 보는 것"** 이 세어진다.
